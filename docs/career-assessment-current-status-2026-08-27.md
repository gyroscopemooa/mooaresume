# 커리어 검사 현재 상태와 다음 구현 순서

작성일: 2026-08-27

이 문서는 `career-assessment-roadmap.md`의 초기 설계 상태를 보완하는 현재 구현 기준이다. 기존 문서는 방법론·범위의 참고 문서로 유지한다.

## 현재 구현됨

1. 업무성향 분석
   - IPIP Big Five 50문항, 결정적 채점, 레이더 차트, 규칙 기반 업무환경 해석
2. 직업흥미 탐색 베타
   - RIASEC/Holland 여섯 활동 영역을 참고한 무아 자체 30문항
   - O*NET Interest Profiler 원문·번역문을 복제하지 않음
3. 직업가치 탐색 베타
   - O*NET Work Importance Locator의 여섯 가치 틀을 참고한 무아 자체 18문항
4. 결과 화면과 커리어 검사 홈
   - 개인 결과는 브라우저 세션에만 임시 보관하고 noindex로 유지
5. 저장용 데이터 모델 초안
   - `career_assessment_sessions`, `career_assessment_answers`, `career_assessment_results` migration은 작성됨
   - 원격 Supabase에는 아직 적용하지 않음

## 아직 미완료

1. 세 탐색 결과를 한 화면에서 읽는 종합 커리어 프로필
2. 로그인 계정에 결과를 저장하고 다시 불러오는 UI·서버 경계
3. 이력서·자기소개서·지원공고를 사용자 선택으로 연결하는 해설 입력 흐름
4. 명시적 실행 시에만 호출되는 AI 해설과 Structured Output 검증
5. 메인·헤더·sitemap의 커리어 전환 경로를 최신 main에 통합
6. 베타 문항의 이해도 인터뷰·전문가 검토·파일럿 검증
7. 검증 뒤 원격 Supabase migration 적용

## 구현 원칙

- 베타 흥미·가치 결과는 표준화 검사, 직업 적합 판정, 채용 예측으로 표현하지 않는다.
- AI는 사용자가 제공한 검사 점수·이력·자소서·공고 밖의 사실을 만들지 않는다.
- AI 해설은 로그인, 자료 선택, 명시적 실행 이후에만 호출한다.
- 원격 DB 변경과 배포는 로컬 검증을 통과한 뒤 별도 적용 단계에서 실행한다.
