# [워크트리 초안 · feature/codex-plan] 커리어 공개 홈·로그인 대시보드 상태

상태: **구현 중 — main 미통합**.

## 사용자 결정

- 공개 커리어 홈은 밝고 간결한 랜딩으로 유지한다.
- 그래프는 개인 결과가 있는 커리어 대시보드에만 표시한다.
- 대시보드의 좌측 사이드바는 로그인 상태에서만 표시한다.

## 화면 상태

1. 비로그인 `/career`: 검사 소개와 실제 시작 링크. 개인 그래프·개인 사이드바 없음.
2. 비로그인 `/career/profile`: 로그인 안내와 `/entry` 링크.
3. 로그인 + 현재 브라우저 결과 없음: 대시보드 껍질 안에 빈 상태와 검사 시작 링크.
4. 로그인 + 현재 브라우저 결과 있음: 실제 응답에서 계산한 업무성향·직업흥미·직업가치 그래프와 다음 행동.

## 한계

원격 Supabase migration이 아직 적용되지 않았으므로, 다른 기기에서도 보이는 저장 결과는 아직 연결하지 않는다. 현재 브라우저에 완료된 검사 응답이 있는 로그인 사용자의 대시보드부터 제공한다.
