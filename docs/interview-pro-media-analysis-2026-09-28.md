# 면접 PRO — 실측 미디어 분석 스튜디오

기준일: 2026-09-28. 로컬 개발 전용 구현. 운영 공개·배포·유료 모델 호출 없음.

## 목적과 사용

### 디자인 정정 — 2026-09-28

고급스럽다는 의미를 연구소풍 로고·장식 파형으로 해석하지 않는다. 사용자 요청에 따라 MOOA SIGNAL LAB, 장식 파형/심전도·영어 섹션 브랜딩을 제거하고 한국어 기능명과 간결한 텍스트 중심으로 정리했다. 실제 계측 그래프는 그대로 유지한다. 정적 아이콘을 실측 신호처럼 설명하지 않는다.

최신 변경: 결과의 중심을 **원문 근거 → 부족한 이유 → 수정 답변 → 다음 연습**인 Astra 답변 피드백으로 옮겼다. 큰 영어 배너와 연구소형 표현은 쓰지 않는다. 파형/영상은 `녹화·음성 근거 확인`에 기본 접힘으로 보존한다. 마이크 시험 녹음의 누락된 전용 스타일도 연결해 카드 넘침을 고쳤다.

**재생 프레임 기반 얼굴·신체 기준점 추적을 새로 구현했다.** 최대8Hz,640px 입력,250ms보다 늦은 결과는 숨긴다. 정지1초 샘플 분석도 별도로 유지한다. 눈/입/홍채/어깨 등의 관찰 좌표이지 정확한 시선·감정·태도 점수가 아니다. 실제 인물 정확도와 모바일 성능 검증은 남아 있다.

예쁜 선을 임의로 그리는 대시보드가 아니라 **원본 답변 → 측정값 → 시점 → 직접 재생 확인**이 이어지는 도구를 만든다. 과학적 표현의 근거는 실측 신호 또는 명시된 모델 추정이어야 한다. 외모·감정·인성·합격확률 점수는 만들지 않는다.

- 독립 화면: `/dev/interview-pro-v2/studio`
- 기존 화면: `/dev/interview-pro-v2`의 결과 단계에 동일 스튜디오 추가. 답변 녹화를 직접 선택할 수 있다.
- 흐름: 파일/답변 선택(또는 직접 입력) → 외부 전송 동의 → 음성 받아쓰기 → 전사 수정/확인 → AI 답변 피드백. 기술 계측은 필요할 때만 펼쳐 직접 재생 확인한다. 관리자 로그인 필요, 자동 유료 호출 없음. 상세는 [AI 연결 문서](interview-pro-feedback-connection-2026-09-28.md).
- 원본 선택 최대3분·80MB. 원본 영상은 탭 메모리만 사용하며 외부에 전송하지 않는다. AI 전사 때 추출한16kHz monoPCM16WAV(최대12MB)만 전송한다. AI 내용 평가는 확인한 질문/답변 텍스트를 전송한다. 로컬 서버 중복호출 방지용 결과는10분 후 메모리에서 능동 해제한다. 새로고침/화면 종료 시 화면 결과는 사라지며 원본 파일을 삭제하지 않는다.
- 카메라 권한을 새로 요청하지 않으며, 사용자가 이미 녹화했거나 선택한 파일만 처리한다.
- `측정 검증 신호`는 실제로 생성한 PCM WAV를 동일 분석기에 입력한다. 실제 사람의 결과로 표시하지 않는다.

## 현재 동작하는 항목

| 화면 | 데이터와 처리 | 해석의 한계 |
|---|---|---|
| 파형 | 16kHz 디코딩 후 100ms 최소/최대 진폭 | 디지털 신호. 화면 범위 밖 값은 잘린다 |
| 음량 곡선 | RMS dBFS, 최대 진폭 | dB SPL·실제 공간 소음·발음 명료도 아님 |
| 저신호 타임라인 | −45dBFS 이하 지속 구간 | 침묵/작은 발화/장비 영향 구별 불가. 직접 들어보기 |
| 음높이 점 | 65–500Hz 주기성 기반 보수적 추정 | 불확실 구간은 공백. 음악/소음/배음 오류 가능 |
| 주파수 지도 | 8kHz 재표본화, 3.2kHz 저역통과, Hann FFT512, 64대역 최대 진폭 | 3.2–4kHz 감쇠는 처리 영향. 밝기=우수함 아님 |
| 최대치 근접 비율 | 절댓값이 임계치에 가까운 PCM 샘플 비율 | 과입력 가능성을 확인하는 신호일 뿐 확정 클리핑 판정 아님 |
| 얼굴 기준점 | 로컬 MediaPipe 모델의 1초 간격 독립 정지 프레임 검출 | 연속 추적·정확한 시선·표정/감정 평가 아님 |
| 화면상 기울기 | 눈 주변 기준점의 2D 선분 각도, 영상 종횡비 보정 | 3D 고개 각도·몸 자세·태도 점수 아님 |
| 검출 상태 | 단일/미검출/복수 얼굴/좌표 불가 분리 | 미검출은 태도 감점 근거가 아니다 |
| 재생 기준점 | VIDEO 모드 현재 프레임 추적, 얼굴/입술/홍채 및 보이는 신체 관절 | 별도 동의, 가림/낮은 신뢰도/늦은 결과는 제외. 시선·감정·외모 판단 없음 |
| AI 답변 피드백 | 확인된 전사/타자 답변 → Astra Structured Outputs, 실제 원문 인용 검증 | 실호출 품질 검증 전. 회사 내부 채점표·10명 독립 평가를 구현한 것이 아님 |

기존1초 샘플 기준점은 **일시정지 + 탐색 완료 + 실제 샘플 시점**에서만 표시한다. 신규 연속 추적은 `재생 영상의 얼굴·신체 기준점 표시`에 동의하면 실행한다. 두 영상 추론을 동시에 실행하지 않으며 참고 영역을 접으면 연속 추적을 종료한다. 검출 안 된 곳에 보간한 가짜 선을 표시하지 않는다. 원본 영상과 오버레이는 같은 종횡비로 맞춘다.

## 구조

- `src/domain/interview-audio-analysis.ts`: 순수 PCM 계산과 검증 범위. 워커/브라우저에 종속되지 않는다.
- `src/lib/interview-media/audio-client.ts`: 길이 사전검사, 네이티브 디코딩 직렬화, 취소, 최대 에너지 채널 선택.
- `audio-analysis.worker.ts`: 메인 UI와 계산 분리, 완료/오류/취소 시 종료.
- `vision-geometry.ts`: 샘플 시각, 좌표/각도/검출 분류와 요약.
- `vision-analysis.ts`: 로컬 모델, 비디오 탐색, 프레임 추론, 타임아웃과 자원 해제.
- `src/components/interview-prototype/media-analysis-studio.tsx` / CSS: 원본 재생, 계측 그래픽, 탐색 UI.
- `audio-encoding.ts`: 원본 영상/메타데이터를 제외한 monoPCM16WAV 인코더.
- `replay-observation-geometry.ts`, `replay-observations.ts`, `replay-observation-overlay.tsx`: 실제 재생 프레임의 관찰 기하학/수명주기/캔버스.
- `interview-feedback-panel.tsx`: 전사 검토/수동 답변/동의/근거형 피드백, 수정 시 과거 결과 무효화.

모델/스키마 버전과 임계값은 분석 결과에 포함된다. AI 응답에도 model/prompt/rubric/schema/usage/requestId를 기록한다. 아직 서버 AnalysisRun의 영구 저장과 연결하지 않았다. 운영 전에는 동의/보존 정책 및 실제 원가 예약·정산 원장을 연결해야 한다.

## 설치·개인정보

`@mediapipe/tasks-vision@0.10.32`를 정확한 버전으로 고정했다. 1.0.1 조사 중 외부 진단 전송 코드가 발견되어 채택하지 않았다. 버전 변경과 알려진 로깅 문자열에 대한 회귀 테스트를 추가했다. 이것만으로 모든 네트워크 동작을 형식적으로 증명하는 것은 아니므로 업그레이드 전 소스/네트워크 재검토가 필요하다.

```sh
npm install
npm run prepare:interview-media
npm run dev -- --hostname 127.0.0.1
```

준비 스크립트는 설치된 정확한 런타임에서 WASM을 복사하고, 모델이 없을 때만 Google 공식 정적 모델을 내려받는다. SHA256 불일치는 실패시키고 기존 모델을 임의 덮어쓰지 않는다. 모델/라이선스/출처는 `public/interview-analysis/mediapipe/NOTICE.md` 참고. 사용자 미디어와 관계없는 공개 모델 자산이다.

기술 계측 시 영상/음성을 외부 업로드하지 않는다. 모델/WASM은 같은 사이트에서 로드한다. **AI 받아쓰기/답변 평가는 별도 동의 후 서버를 거쳐 OpenAI로 음성/텍스트를 전송한다.** `store:false`가 공급자의 모든 보존 정책을 없애는 것은 아니다. 개발환경의 공용 Clarity/Naver/Google 태그도 제외했다(운영 동작 유지). HMR 등 네트워크 자체가 전혀 없다는 뜻은 아니다.

브라우저 `decodeAudioData`는 전체 파일을 디코딩하고 중간 취소할 수 없다. 길이 사전검사/용량 상한/직렬 대기로 일반적인 과다 할당·반복 실행을 줄였으나 거짓 메타데이터를 가진 파일에 절대적인 메모리 상한을 보장하지 않는다. 알려진 장시간 파일과 길이 미상 외부 파일은 분석 전 차단한다. 자체 녹화 WebM은 기록된 실제 녹화 시간을 전달한다.

공식 참고: [decodeAudioData](https://developer.mozilla.org/en-US/docs/Web/API/BaseAudioContext/decodeAudioData), [OfflineAudioContext](https://developer.mozilla.org/en-US/docs/Web/API/OfflineAudioContext).

## 검증 기록

최신 09-28: 본 작업 트리의 면접 관련27개 파일/200개 테스트, 전체 타입검사, 변경 범위 ESLint 통과. 작업트리 복제본까지 탐색한 광역 `vitest run interview`는 복제본 의존성 오류가 있어 중단했고, 실제 `src` 파일 목록으로 범위를 지정해 재실행했다. 이어서 신규/수정 범위16파일/156개 테스트도 통과했다. 이후 근거 시점 연결 보완의 최종 결과는 변경 로그 참고.

- 브라우저360px·390px: 마이크 카드/본문의 가로 넘침0, 시험 녹음 텍스트가 테두리 안에서 줄바꿈됨.
- 브라우저: 답변 피드백이 상단, 기술 계측 기본 접힘, 미인증 시 관리자 안내, 진단 합성 신호는 AI 전송 차단.
- 실제 검증 WAV의 브라우저 디코딩/워커가 변경 후에도 평균−7.0dBFS·저신호2초·주기 중앙값200Hz 계산.
- 인증된 로컬status 요청에서 configured/enabled/authorized=true, Astra/Whisper 설정 확인. **OpenAI 실호출과 실제 인물 추적 테스트는 안 했으므로 품질 통과로 간주하지 않는다.**

아래는 최초 계측 구현의 검증 기록이며 신규 AI/추적 품질 인증과 구분한다.

- 오디오 도메인 26개: 사인파·무음·잡음·DC·고주파·클리핑·FFT·최대 길이·범위 검증.
- 오디오 클라이언트 15개: 길이 사전 거절, 취소/재시도 직렬화, 채널 선택, 워커 오류·정리, 검증 WAV.
- 영상 16개: 기하학 8개, 브라우저 수명주기 모의 7개, 정확한 런타임 버전/로깅 회귀 1개.
- 스튜디오 통합6개: 분석 전 빈 상태, 자체WebM 길이 전달, 음성전용 처리, 영상/오디오 길이 분리, 재생/탐색 오버레이 숨김, 취소 뒤 늦은 응답 무시(디코더/모델 모의).
- 실제 IAB: 검증 WAV 디코딩/워커 실행 성공. 평균 −7.0dBFS, 최대 0.0dBFS, 저신호2.0초, 피치 중앙값200Hz, 저신호 구간 버튼으로5초 이동 확인.
- 실제 IAB: 기존 로컬 세로 홍보 영상(720×1280, 약60초)으로 모델 다운로드/CPU 추론/61프레임 탐색 완료. 얼굴이 없는 영상에서61개 미검출, 얼굴 선 없음. 영상15초 탐색과 오디오 분석 성공.
- 새로고침한 개발 화면의 script 목록에서 외부 방문 분석 태그 부재 확인.
- 모바일390px/360px 렌더 및 가로 넘침 없음 확인. 모바일은 재생→분석 시작/요약→그래프→영상 기준점 순서로 배치했다. 파일 해제 후 결과 초기화/분석 버튼 비활성도 확인. 실기기 iOS/Android 테스트와 실제 얼굴의 양성 검출/정확도 검증은 아직 안 했다.
- 타입검사와 변경 범위 ESLint 실행. Next dev 동시 생성으로 손상된 임시 route types는 Next 내장 생성기로 복구했다(소스 변경 아님).

## 다음 단계 / 아직 없는 기능

1. 동의받은 실제 면접 영상으로 단일 얼굴/안경/측면/가림/조명·세로/가로·복수 인물 검증. 현재 모델 실작동 확인은 미검출 케이스이며 얼굴 검출 정확도 인증이 아니다.
2. iOS Safari/Android Chrome의 codec·메모리·처리시간·중단/백그라운드 복귀 검증. 1초 간격이라도 CPU 추론은 순간적으로 메인 스레드를 점유한다. 느린 기기에는 다운샘플링/워커 격리 추가 검토.
3. 전사 및 Astra 피드백은 연결했다. 사용자가 승인한 실제 음성1건으로 받아쓰기·원문 인용·수정 예시 품질 검증이 다음이다. 현재 전사는 구간 타임스탬프이며 정확한 발음·유창성 평가 엔진이 아니다.
4. 10관점 종합 평가·동적 질문/끼어들기·세션 단위 평가·원가 원장·서버 저장은 미구현. 현재 한 답변의 내용 피드백이며, 기존 입퇴장 평가 seed가 자동 실행되는 것은 아니다.
