# 면접 PRO 홍보 및 다중 관점 초안

상태: 로컬 홍보 미리보기. 공개 출시/결제/실제 다중 평가 미연결. 기존 시안과 내부 기준을 교체하지 않는다.

## 핵심 카피

답변만 준비하지 마세요. 면접 전체를 준비하세요.

면접은 첫 질문 전에 시작됩니다.
같은 답변도, 면접관마다 다르게 들립니다.
점수 하나로 당신을 설명하지 않습니다.
당신도 질문할 수 있습니다.
무난함만이 정답은 아니니까.

## 10개 관점 목표

직무 이해 / 실무 수행 / 경험의 근거 / 문제 해결 / 의사소통 / 경청과 협업 / 지원 동기 / 성찰과 성장 / 지원자 질문 / 전체 면접 수행.

이는 실제 인물 10명이나 독립된 모델 10개가 아니라 서로 다른 평가 초점이다. 현재 실행 엔진이 아니며 10개가 최적이라는 검증도 없다. 4개 핵심 관점과 10개 확장 관점의 품질·중복·지연·원가를 비교한 뒤 출시 구성을 확정한다. 매 질문마다 10번 호출하는 것은 기본 설계로 확정하지 않는다.
종합은 단순 평균만 쓰지 않는다. 공통 강점, 견해 차이, 근거, 직무별 해석을 함께 제시하고 같은 증거의 중복 감점을 피한다. 한 모델의 상관된 오류를 10명의 합의라고 포장하지 않는다.

## 공개 가능한 철학

지원자는 답변만 하는 사람이 아니다. 예절 정답 맞히기가 목적이 아니다. 특정 직무의 강점과 맥락별 차이를 보여준다. 관찰 가능한 근거로 설명한다.
창업자의 관점, 공개 자료, 동의받은 현직자 의견은 출처와 검증 상태를 구분해 내부 기준에 반영한다. 실제 전문가 참여가 없으면 현직자 심사라고 홍보하지 않는다.

## 비공개 경계

홍보 데이터에는 역할의 큰 이름과 사용자 경험만 넣는다. 내부 프롬프트·가중치·임계값·검증 사례·원문 평가표는 넣지 않는다. 현재 관리자 편집기의 내부 상수는 클라이언트 import 방식이므로 운영 전 서버 전용 이전 및 번들 노출 검증이 별도로 필요하다. 관리자 페이지 인증만으로 정적 번들의 비밀이 보장된다고 주장하지 않는다.

## 현재 표현과 출시 후 후보

- 현재: ‘10가지 관점의 AI 면접관을 목표로 설계합니다.’
- 실제 구현·검증 후 후보: ‘10가지 AI 평가 관점으로 공통 강점과 의견 차이를 확인하세요.’
- 금지: ‘실제 사람 10명이 평가’, ‘현직자 10명 심사’(참여 근거 없음), ‘입장부터 분석 중’(미구현), 합격 보장·비공개 기업 기준 재현.

## 구현 위치 및 수정 방법

`/dev/interview-pro-v2/preview`는 development만 열리고 운영은 404다. robots noindex 적용, 구매 CTA 없음.
`src/domain/interview-marketing-draft.ts`에서 카피·섹션 배열을 수정/추가/삭제할 수 있다. 공개 메뉴에는 연결하지 않았다.
출시 전 게이트: 실제 기능 검증, 문구와 제공 범위 일치, 분석 동의, 내부 자료 서버 경계, 모바일 실기기 확인, 원가/지연 평가.
