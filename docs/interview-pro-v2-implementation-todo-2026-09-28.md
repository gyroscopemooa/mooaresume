## 2. 실제 기업 전형에 대한 판단

`실제 기업 AI 면접은 아바타가 앉아 대화하는 방식이 대부분이다`라고 보면 안 된다. 시장 전체의 정확한 방식별 점유율 통계는 확인되지 않았지만, 대표적인 기업용 비동기 영상면접은 다음 구조를 사용한다.

```text
장비 확인
  → 질문 공개
  → 생각할 시간
  → 카메라·마이크 녹화
  → 제한시간 답변
  → 제출 또는 자동 종료
  → 다음 질문
```

- HireVue는 일방향·비동기 영상면접을 `정해진 질문에 지원자가 영상을 녹화해 답하는 방식`으로 설명하며, 일반적으로 질문 확인 후 준비시간과 제한된 답변시간이 있다고 안내한다.
- JOBDA 공식 수련 페이지는 웹캠·마이크 환경 확인, 영상 답변 녹화, 답변 영상 복기를 핵심 흐름으로 제공한다.
- JOBDA 응시자 가이드도 선택된 영상질문에 생각하기 시간이 주어지고 답변을 녹화·제출하는 구조를 안내한다.
- 사람인 모의면접 역시 카메라·마이크·스피커 연결 후 응시하고 답변별 영상과 분석을 제공한다. 다만 카메라는 선택 가능하므로 이것은 기업 전형 그 자체보다 연습 제품의 유연성에 가깝다.

따라서 제품 우선순위는 다음과 같다.

1. 실제 시험형 카메라 UI
2. 포맷별 시간·재녹화·질문 표시 규칙
3. 안정적인 녹음·녹화·복구
4. 납득 가능한 답변 분석
5. 대화형 후속 질문
6. 사람형 AI 아바타

```text
무아레쥬메
├─ Resume

│
├─ Interview PRO
│  ├─ Interview Practice
```

## 8. 서버 제어형 전형 프리셋

```ts
type InterviewPreset = {
  presetId: string;
  displayName: string;
  sourceStatus: "official" | "user_confirmed" | "estimated";
  verifiedAt: string | null;
  responseMode: "recorded_video" | "voice" | "conversational";
  questionPresentation: "text" | "tts" | "prerecorded";
  prepSeconds: number;
  answerSeconds: number;
  questionCount: number;
  retryPolicy: "none" | "one" | "configurable";
  cameraRequired: boolean;
  followUpsEnabled: boolean;
};
```

위 타입은 제품 요구 예시이며 현 단계에서 그대로 DB 테이블을 만들라는 뜻은 아니다.

## 15. 출시 게이트

다음 조건을 모두 만족하기 전에는 유료 면접 PRO로 공개하지 않는다.

- [ ] 주요 모바일·데스크톱 브라우저에서 권한·녹화·재생이 검증됨
- [ ] 네트워크 중단 후 답변 유실 방지 또는 명확한 재시도 경로가 있음
- [ ] 중복 AI 호출과 중복 과금이 방지됨
- [ ] STT 오류가 정성 평가로 위장되지 않음
- [ ] 모든 정성 피드백에 이유 또는 근거가 있음
- [ ] 영상·음성·전사문 삭제가 실제 저장소까지 반영됨
- [ ] 공식 확인되지 않은 기업 포맷이 사실처럼 노출되지 않음
- [ ] 합격확률·얼굴·감정·외모 점수가 없음
- [ ] 실제 사용자 5~10명이 전형 흐름과 결과를 이해할 수 있는지 관찰 테스트함
- [ ] 회차당 원가와 59,000원 상품의 최대 사용 원가가 측정됨
- [ ] 실사용 분포에서 평균 5,000원 이하, 구매 건별 10,000원 하드캡이 서버에서 검증됨

## 16. 개발 착수 순서

```text
기존 텍스트 면접 안정화
→ 프리셋 스키마와 세션 상태머신
→ 장비 사전점검
→ 음성 녹음 + STT
→ 질문 TTS
→ 카메라 녹화형 전형 시뮬레이터
→ 실패 복구·보존·삭제
→ 답변 평가와 리포트
→ 약점 재훈련·세션 비교
→ 대화형 AI 전형
→ 전형 안내문 분석과 비공개 맞춤 프리셋
→ 소수 공식 프리셋 운영
→ 아바타 필요성 재평가
```

다음 실제 개발 작업은 `기존 텍스트 모의면접의 질문 신뢰 경계와 턴 예약 보완`이다. 카메라 기능부터 바로 붙이지 않는다.
