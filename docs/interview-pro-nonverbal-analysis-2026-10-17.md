# 면접 PRO 비언어 전달 분석 — 기술 구조와 도입 경계

## 목적 분리

- `AI 답변 분석`: 질문 적합성, 논리, 경험 근거, 직무 적합성만 평가한다.
- `전달 방식`: 원음과 영상에서 직접 관찰한 말투·운율·속도 변화·머뭇거림·얼굴/자세 변화만 다룬다.
- 전달 방식 결과를 내용 분석 API에 보내지 않는다. 원본 음성·영상도 현재 OpenAI 피드백 API에 보내지 않는다.

## 현재 실제 구현

| 항목 | 근거 | 현재 판정 범위 |
| --- | --- | --- |
| 말끝 전달 | 원음 100ms 프레임에서 발화로 구분된 앞/뒤 구간의 상대 레벨 | 마지막 구간이 앞부분보다 현저히 작아졌는지. 마이크 영향 때문에 자신감으로 확정하지 않음 |
| 발화·긴 멈춤 | 기기 내 Silero VAD ONNX가 원음에서 찾은 발화 구간 | 답변 중간의 1.5초 이상 발화 단절과 실제 타임코드. 단순 저신호를 침묵으로 부르지 않음 |
| 억양 변화 | 원음에서 추정한 유성 프레임의 기본주파수 분포 | 높낮이 변화가 매우 좁은지 또는 변화가 관찰되는지. 감정 판정 아님 |
| 속도 급변 | 구간 시각이 있는 STT의 구간별 글자/시간과 같은 답변의 중앙값 비교 | 다른 구간보다 급격히 빨라지거나 느려진 실제 구간. 구간 전사가 없으면 보류 |
| 머뭇거림 | 구간 전사에 남은 `어·음·그`와 원음 구간 | 두 구간 이상 반복될 때만 표시. STT 삽입/생략 가능성을 명시 |
| 얼굴 방향 반복 변화 | MediaPipe Face Landmarker의 0.5초 로컬 표본에서 얼굴 상자 안 코 위치의 좌우 변화 | 좌우 얼굴 방향 변화가 반복된 구간. 눈 시선으로 부르지 않음 |
| 큰 화면상 이동·이탈·기울기 | 0.5초 얼굴 기준점 표본 | 실제 타임코드와 함께 확인. 태도·성격 점수로 변환하지 않음 |
| 상체 자세 | 0.5초 MediaPipe Pose Landmarker의 어깨·골반 기준점 | 충분한 표본에서 한쪽 상체 기울기가 지속되는지. 검출 부족 시 보류 |

녹화 전 카메라 분석에 동의한 면접 세션은 결과 진입 후 별도 버튼 없이 영상 분석을 자동 시작한다. 동의하지 않았거나 음성 전용 답변이면 `영상 분석 미실시`를 명확히 표시한다. 동의를 철회하면 진행 중 작업을 중단하고 기기 메모리의 영상 분석 결과를 즉시 비운다.

짧은 표본의 우연한 흔들림을 습관으로 오인하지 않도록 얼굴 방향 반복·머리 기울기·상체 기울기 코칭은 15초 이상 영상과 24개 이상의 유효 0.5초 표본이 있을 때만 생성한다. 얼굴 방향 반복은 최초·최종 변화가 6초 이상 떨어져 있어야 한다.

## 아직 구현하지 않은 판정

### 한국어 발음 정확도·단어 명료도

일반 STT가 맞게 받아썼다는 사실만으로 발음이 명료하다고 판정할 수 없다. 신뢰할 수 있는 구현에는 한국어 음소 모델, 기준 전사와 음소 강제정렬, GOP 또는 한국어 화자 대상으로 검증된 발음 평가 모델이 필요하다. 관련 연구는 wav2vec 2.0/HuBERT 표현과 GOP·forced alignment를 사용하지만, 현재 제품에 즉시 넣을 수 있는 검증된 브라우저용 한국어 면접 발음 모델은 확인하지 못했다.

### 자신감·감정·성격

음높이·음량·속도·표정으로 심리 상태를 확정하지 않는다. `끝말이 작아짐`, `속도가 급변함`, `정면 기준 얼굴 방향이 반복적으로 달라짐`처럼 관찰 가능한 행동만 말하고, 면접관에게 전달될 수 있는 인상은 가능성 표현으로 제한한다.

### 정확한 시선·고개 숙임

상체 기울기는 배치 Pose Landmarker로 구현했지만, 정확한 고개 숙임과 카메라 응시는 구현하지 않았다. 다음 단계는 얼굴 변환 행렬을 검증해 고개 각도 변화를 관찰하는 것이다. 눈동자 좌표만으로 카메라 응시율을 만들지 않는다.

### 손·다리, 표정 품질, 복장·머리·배경

현재 배치 분석은 얼굴과 상체 기준점까지만 결과 판정에 사용한다. 손·다리 검출, 미소의 자연스러움, 복장·머리 정돈, 배경·조명에 대한 의미 평가는 아직 구현하지 않았다. 이 항목은 단일 프레임 규칙이나 얼굴 생김새 점수로 대체하지 않으며, 실제 촬영 환경·피부색·안경·마스크·조명 조건을 포함한 검증 세트 또는 선택 동의 기반 비전 모델 검토가 선행되어야 한다.

## 개인정보·전송·비용

- 얼굴·Pose Landmarker와 VAD는 브라우저 기기 안에서 실행하며 원본 영상은 OpenAI나 별도 영상 API로 전송하지 않는다.
- 영상 결과도 현재 내용 분석 API 입력에 포함하지 않는다. 내용 분석은 사용자가 확인한 질문·답변 텍스트만 사용한다.
- 현재 로컬 영상 분석의 API 호출 비용은 0원이다. 대신 모델 최초 다운로드, 브라우저 CPU/WASM 사용량과 저사양 PC 처리 시간이 발생한다.
- 정확한 시선·복장·배경 같은 미구현 항목을 외부 VLM으로 확장하면 명시적 별도 동의, 영상/프레임 전송 고지, 보관 정책과 건별 비용 검토가 필요하다.

## 검토한 추가 기술

### Silero VAD ONNX

- 용도: 실제 발화/비발화 구간을 분리해 긴 쉼, 발화 시작·종료, 말 끌기를 더 정확하게 측정한다.
- 실행: 8kHz/16kHz ONNX를 기기 내에서 실행할 수 있다. 공식 FAQ는 ONNX의 edge 실행과 16kHz 처리를 안내한다.
- 비용: API 호출 비용은 없지만 모델·ONNX Runtime 다운로드 용량, 초기 로딩, CPU/WASM 비용이 발생한다.
- 도입 결과: `@ricky0123/vad-web 0.0.31`의 NonRealTimeVAD와 Silero legacy ONNX를 같은 출처의 로컬 자산으로 고정했다. 원음은 브라우저 밖으로 나가지 않는다. 배포 전 실제 브라우저 성능과 모델 자산 해시 검증을 추가해야 한다.
- 출처: https://github.com/snakers4/silero-vad 및 https://github.com/snakers4/silero-vad/wiki/FAQ

### openSMILE / eGeMAPS 계열 운율 특징

- 용도: F0, loudness, spectral flux, jitter/shimmer 계열의 표준화된 음성 특징을 추출하는 데 적합하다.
- 한계: 특징 추출 자체가 면접 코칭의 정답이나 자신감 판정은 아니다. 상업 제품에서는 라이선스와 별도 학습/검증 데이터를 확인해야 한다.
- 비용: 로컬 실행이면 호출 비용은 없지만 WASM 통합·라이선스·기기 성능 비용이 있다.
- 출처: https://audeering.github.io/opensmile/ 및 https://github.com/audeering/opensmile

### 한국어 발음 평가 모델

- 연구 근거: 한국어 대상 자동 발음 평가는 wav2vec 2.0/HuBERT 표현과 GOP/강제정렬을 결합한 연구가 있다.
- 한계: 연구 데이터의 화자·과제와 취업 면접 자유발화는 다르다. 별도 검증 없이 점수나 `발음이 나쁨` 판정으로 출시하지 않는다.
- 비용: 자체 호스팅 시 GPU/모델 운영비와 평가 데이터 구축비가 크며, 외부 API 사용 시 음성 전송 동의·보관 정책·건당 비용 검토가 필요하다.
- 출처: https://www.isca-archive.org/interspeech_2022/kim22k_interspeech.pdf

## 다음 구현 우선순위

1. 구간 시각을 반환하지 않는 현재 로컬 STT에 청크/단어 타임스탬프를 추가해 속도·머뭇거림 분석을 기본 경로에서도 가능하게 한다.
2. 얼굴 변환 행렬을 검증해 지속적인 고개 숙임을 관찰하되 눈 시선으로 확대하지 않는다.
3. 한국어 발음 평가는 별도 평가 데이터와 전문가 라벨로 정확도를 검증한 뒤 도입 여부를 결정한다.
