# 커리어 AI 심층해설 흐름

상태: UI 프로토타입 / 실제 결제·외부 AI 호출 보류

## 사용자 흐름

1. 무료 검사 완료 후 간편 결과를 즉시 확인한다.
2. 커리어 홈 또는 각 결과의 `심층해설 확인하기`에서 `/career/ai?scope=interest|work_style|work_values|combined`로 이동한다.
3. 그 화면에서 완료한 개별 검사 또는 세 검사 종합을 고른다.
4. 출시 시 로그인 → 사용자가 직접 제공하는 경험·이력서·자소서·공고 자료 선택 → 제공 범위와 가격 확인 → 결제 → 실제 심층해설 리포트 순서로 진행한다.
5. 실제 리포트는 결과의 상위 축, 근거가 된 사용자 자료, 추가 확인 질문, 지원서·공고를 읽을 기준을 구분하여 제공한다.

## 현재 구현 상태

- 무료 기본 결과와 AI 해설 선택 화면: 구현됨.
- `/career/ai/sample?scope=interest`: 실제 사용자 데이터와 분리된 완성 리포트 UI 예시.
- 로그인 이후 검사 결과 자동 저장: 구현 경로 존재, 대상 Supabase migration 적용 후 인증 저장 검증 필요.
- 심층해설 결제 entitlement, 자료 업로드 선택, OpenAI 호출, 실제 리포트 저장: 아직 구현하지 않음.

## 금지/안전 경계

- 직업 적합성·합격 가능성·채용 결과를 판정 또는 예측하지 않는다.
- 사용자가 제공하지 않은 경력·성과·직무 희망을 만들어 내지 않는다.
- 검사 점수와 사용자 제공 자료, AI의 해석을 한 문서 안에서도 구분한다.
- 가격·결제 버튼·AI 호출은 실제 연결 전에는 작동하는 것처럼 표시하지 않는다.

## 다음 구현 순서

1. 실제 심층해설 상품의 범위·가격·환불 조건을 확정한다.
2. 로그인 사용자에게서 어떤 지원 자료를 받을지 명시적으로 선택받는다.
3. 결제 entitlement와 `AnalysisRun`/`AnalysisResult` 저장 경계를 기존 이력서 분석 도메인과 충돌 없이 설계한다.
4. 서버 전용 OpenAI 호출과 Structured Output 스키마를 연결하고, 샘플과 실제 결과를 완전히 분리한다.
## 심층해설이 기본 결과와 다른 이유

기본 결과는 무료로 상위 축과 간단한 설명을 즉시 제공한다. 심층해설의 유료 가치는 결과를 더 길게 말하는 데 있지 않다.

- **교차 해석**: 한 검사 안의 상위 축뿐 아니라, 완료한 여러 검사 사이의 공통점·충돌 지점을 읽는다.
- **근거 연결**: 사용자가 명시적으로 제공한 이력서·자소서·공고와 검사 결과를 대조한다. 자료에 없는 사실은 만들지 않는다.
- **불확실성 표시**: 미응답·반복 응답·지나치게 빠른 응답은 결과의 확정 근거가 아니라 재확인이 필요한 신호로만 쓴다. 응답 시간으로 성격·능력·직업 적합성을 판정하지 않는다.
- **질문형 해설**: 단정형 “당신은 이런 사람” 대신, 확인할 경험 질문과 다음 행동을 제공하고 사용자의 답으로 가설을 갱신한다.
- **지원 준비 연결**: 코드/유형, 강점으로 쓸 수 있는 방식, 주의할 환경, 더 살펴볼 직무 분야를 먼저 간결하게 제시한다. 직업명을 맞히거나 합격을 예측하는 대신, 공고에서 확인할 업무 조건과 지원서에 골라 쓸 경험의 기준을 만든다.

전문 임상가의 평가는 면담, 표준화된 척도, 윤리·법적 책임, 임상적 판단을 포함한다. MOOA의 AI 심층해설은 이를 대체하거나 전문가인 것처럼 말하지 않는다. 고용·진로 탐색 문맥에서 사용자 자료를 정리하고 질문을 설계하는 보조 리포트다.

## 예시 리포트 페이지

- `/career/ai/sample?scope=interest` — **1 / 2**: 결과 축, 해석의 근거, 데이터 품질 경계, 다음 행동을 보여주는 요약 대시보드.
- `/career/ai/sample?scope=interest&page=2` — **2 / 2**: 실제 경험과 공고를 연결하는 편지형 상세 해설 예시.

두 페이지 모두 예시 인물의 데이터이며 실제 사용자 결과·결제 후 결과와 분리한다.

## RIASEC 탐색 유형 표기

상위 3개 영역의 순서는 120개(6P3) 코드가 될 수 있다. UI는 상위 두 영역으로 30개 읽기 쉬운 별칭을 고르고, 세 번째 영역은 코드와 세부 맥락으로 표시한다. 이 별칭은 무아 자체 커리어 탐색 라벨이며 표준화 성격 유형·임상 진단·직업 적합 판정이 아니다.

## 직무·산업·자격 탐색 표기 원칙

심층해설은 직무 후보, 산업 분야, 진로 경로, 자격/학습 후보를 서로 다른 섹션으로 제시할 수 있다. 모두 유형만으로 확정 추천하지 않고, 실제 경험·희망 업무·공고 조건을 대조하는 후보로 표기한다. 자격명은 공식 주관기관 정보로만 관리하며, 응시요건·일정·유효성·채용 요구사항은 표시 시점에 다시 확인한다. 현재 예시 화면에는 데이터·분석 경로의 SQLD, 진로·고용서비스 경로의 직업상담사 2급을 조건부 후보로만 넣는다.
