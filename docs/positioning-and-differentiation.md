## 출발한 걱정

> "채용공고 넣고 이런 것도 사실 챗지피티에 넣으면 되는 부분이긴 함"

맞는 걱정입니다. **공고 분석을 주력 차별화로 밀면 위험합니다.**

- ChatGPT는 공고 기반 이력서·자소서 피드백을 공식적으로 안내합니다.
- 사람인은 공고 맞춤형 자소서 + AI 멘토 코칭 + 키워드 개선 + 문장 다듬기 + AI 의심 방어까지 이미 제공합니다.
- 커리어마이징도 경험정리 → 기업분석 → 공고분석 → 자소서 → 모의면접 구조를 갖고 있습니다.

**공고 입력은 차별화 기능이 아니라 시스템을 돌리는 재료 중 하나로 내려야 합니다.**

## 판단 기준 두 줄

```
"ChatGPT에서도 할 수 있음"  → 상관없음
"ChatGPT에서 하는 게 더 편함" → 위험함
```

쿠팡이 온라인 쇼핑을 발명한 게 아니고 배민이 배달을 발명한 게 아닙니다. **편리함·속도·확실성에 돈을 내는 경우가 아주 많습니다.** 처음부터 ChatGPT가 절대 못 하는 무언가를 찾을 필요는 없습니다.

## 파는 것은 AI가 아니라 채용 심사 과정

ChatGPT에서는 사용자가 **무엇을 물어봐야 하는지부터** 알아야 합니다.

```
ChatGPT:  📎 첨부 → "무엇을 도와드릴까요?"

무아레쥬메: 원문
            ↓ 15초 심사
            ↓ 탈락 위험
            ↓ 공고 X-Ray
            ↓ 경험 증거 확인
            ↓ 필요한 부분만 수정
            ↓ 최종 제출 점검
            ↓ 이 자소서로 들어올 면접 질문
```

경쟁 구도는 `무아레쥬메 vs ChatGPT`가 아니라 **`ChatGPT 붙잡고 30~60분` vs `돈 조금 내고 5분`**입니다.

## 한 문장 재정의 (후보)

> ~~AI 자기소개서 첨삭 서비스~~
> **제출하기 전, 채용담당자의 시선으로 내 지원서를 검수하는 서비스**

구조도 `WRITE → ANALYZE → FIX`가 아니라 **제출본 → 심사 재현 → 제출 판정**입니다.

## 밀어야 할 네 가지

### ① 15초 서류심사

점수판(`맞춤법 82점`)이 아니라 **인사담당자가 처음 15초에 무엇을 보는가**로:

- 첫 문장에서 무엇이 잡히는가
- 지원동기가 바로 보이는가
- 숫자·성과가 눈에 들어오는가
- 읽다가 어디서 이탈할 가능성이 있는가

ChatGPT도 시키면 합니다. **차이는 사용자가 이 프레임을 스스로 떠올려 프롬프트로 써야 한다는 것**입니다.

### ② 감점요소 제거, 개성 유지 — 브랜드 철학

대부분의 AI 자소서 서비스: `더 좋은 자소서로 만들어드립니다.`
무아레쥬메: **`정답을 만들지 않습니다. 떨어질 이유를 줄입니다.`**

- ❌ AI가 생각하는 최고의 자소서 / 무조건 예쁘게 다시 쓰기
- ✅ 지원자의 경험은 유지
- ✅ 과장·뻔한 표현·논리 비약 제거
- ✅ 인사담당자가 오해할 부분 표시
- ✅ 일부러 남겨둘 개성은 사용자가 선택

이미 구현된 **첨삭 방향 스위치(안정형/균형형/소신형)**가 정확히 여기에 붙습니다. `docs/analysis-consistency-and-rounded-editing-philosophy.md`와 같은 뿌리입니다.

### ③ 첨삭 결과가 아니라 **제출 가능 여부**를 파는 것

사용자가 진짜 궁금한 것은 `이 문장이 더 자연스러운가?`가 아니라 **`이거 지금 제출해도 됨?`**입니다.

```
제출 준비도
82 / 100 · 제출 가능

🟢 직무 경험 충분
🟢 지원동기 명확
🟡 입사 후 포부 구체성 부족
🔴 2번·3번 문항 경험 중복
🟡 AI 작성처럼 보일 가능성이 있는 표현 3개
🟢 공고 핵심요건 8/9 반영

남은 핵심 수정 3개
```

**산출물 자체가 달라지므로 ChatGPT 대화와 경험이 완전히 갈립니다.** 지금 `readiness`가 이미 있으므로 가장 빨리 닿을 수 있는 항목입니다.

### ④ X-Ray — 점수 그래프가 아니라 요구 ↔ 증거 대조

| 공고가 원하는 것 | 자소서 증거 | 판정 |
|---|---|---|
| 자동차 제조 경험 | 현대차 차체4부 경험 | 🟢 |
| 품질 문제 개선 | 불량원인 분석 경험 | 🟢 |
| 협업 | 구체적인 사례 없음 | 🔴 |
| 안전의식 | 위험성평가 경험 | 🟢 |
| 데이터 활용 | 언급 없음 | 🟡 |

**`공고 단어를 넣었는가`가 아니라 `그 역량을 증명했는가`.** 키워드 매칭과 여기서 갈립니다.

## FINAL — 모의면접 하나 추가로는 약함

**서류에서 면접으로 이어지는 시스템**이어야 합니다.

자소서에 `불량률을 20% 개선했습니다`가 있으면 FINAL이 자동으로:

> "20%의 기준은 무엇인가요?"
> "본인이 직접 한 일은 무엇입니까?"
> "팀 성과를 본인 성과처럼 표현한 것은 아닌가요?"

그리고 답변 후 **자소서 ↔ 면접 답변 모순 탐지**까지.

## 경험은행 — 가장 강한 후보

처음 한 번만 경험을 등록해 둡니다: 현대차 차체 생산, 품질검사, 불량 개선, 팀 프로젝트, 아르바이트, 자격증, 교육, 수상, 실패 경험 …

그러면 공고마다:

```
삼성 공고   → 경험 A, C, F가 가장 적합합니다.
현대차 공고 → 경험 A, B, D가 가장 적합합니다.
공기업 공고 → 기존 경험 중 B를 이런 방향으로 쓰는 것이 적합합니다.
```

문항 배분까지: `문항 1 → 경험 A`, `문항 2 → 경험 D`, `문항 3 → 경험 B`.

**ChatGPT에는 지원할 때마다 내 경력을 다시 설명해야 합니다.** 무아레쥬메는 `나를 이미 알고 있는 취업 전용 AI`가 됩니다.

시간이 지날수록 자산이 쌓입니다:

| 회차 | 상태 |
|---|---|
| 1회차 | 공고 → 경험매칭 → 자소서 |
| 5회차 | 경험 15개 저장 → 바로 최적 경험 추천 |
| 20회차 | 어떤 경험을 많이 썼는지 / 남았는지 / 문항 중복까지 관리 |

처음에는 편해서 들어왔다가 나중에는 **"내 취업 데이터가 다 여기 있어서 여기 쓰는 게 편함"**이 됩니다.

## 밀고 싶은 조합

**한 번 결제 + 원클릭 과정 + 경험은행 + 제출 준비도**

구독이 아닌 것도 장점입니다. ChatGPT Plus를 매달 낼 생각이 없는 사람이 *"이번에 현대차 지원하는데 자소서 한 번만 제대로 봐야겠다"* 하며 4,900 / 12,900 / 19,900을 한 번 내는 심리적 장벽은 훨씬 낮습니다.

단순 GPT wrapper면 12,900원이 아깝지만, **"뭘 물어봐야 할지도 모르는데 지원서 하나 넣으면 제출 전 검증이 끝난다"**면 이야기가 다릅니다.

## 시장

고용노동부 2026년 조사에서 구직자가 원하는 AI 고용서비스 중 **경력설계와 이력서·자기소개서 컨설팅 수요가 높게** 나타났고 정부도 관련 서비스를 확대 중입니다.

즉 문제는 `AI 자소서가 필요 없다`가 아니라 **`그냥 AI 자소서면 ChatGPT 쓰지 왜 돈 냄?`**입니다.

## 짚어둘 긴장 — 아직 답 없음

1. **한 번 결제와 경험은행은 서로 당깁니다.** 락인은 재방문에서만 값을 하는데, 1회 결제 모델은 사람을 떠나보냅니다. 경험은행이 살려면 *다음 지원서로 돌아올 이유*가 필요합니다 — 결과 보고 보상(무료 이용권)이 이미 그 역할을 노리고 있습니다.
2. **경험은행의 콜드 스타트.** 첫 사용자에게는 아무 값도 없습니다. 1회차부터 이득이 나려면 첫 분석에서 경험을 **자동 추출해** 은행에 넣어줘야 합니다. 사용자가 폼을 채우게 하면 안 됩니다.
3. **위 넷 중 기술적으로 방어되는 것은 없습니다.** 전부 복제 가능합니다. 시간이 지나 복제되지 않는 유일한 자산은 **결과 데이터**(어떤 지적이 실제 합격과 어떻게 연결되는가)입니다. 이미 수집 구조가 있습니다.

## 다음에 할 일 (제안 순서)

1. **제출 준비도 화면** — 이미 있는 `readiness`를 판정형으로 재배치. 가장 적은 작업으로 가장 큰 인상 변화.
2. **X-Ray를 요구 ↔ 증거 표로** — FINAL 검증 탭에 이미 비슷한 재료가 있습니다.
3. **경험 자동 추출** — 분석 결과에서 경험을 뽑아 저장. 경험은행의 씨앗이자 콜드 스타트 해법.
4. **경험은행 화면과 공고별 추천.**
5. **FINAL 면접 답변 ↔ 자소서 모순 탐지.**
6. 문구·포지셔닝 교체는 위가 하나라도 서고 난 뒤에. **없는 것을 말로 먼저 약속하지 않습니다.**
