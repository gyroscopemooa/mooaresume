## 원문에서 채택한 판단 구조

- 긍정: 질문에 직접 답함, 본인 역할·학습·추가 근거, 모르는 범위 구분, 앞선 설명과 연결한 질문.
- 개선 후보: 반복적 질문 이탈, 역할 설명 부족·확인 필요한 모순, 반복적 말 끊기, 진행 방해. 표현 차이나 전사 오류만으로 거짓말·무례·인성을 판정하지 않는다.
- 무감점: 단추, 정확한 손 위치, 노크 횟수, 정형 인사 문구 차이, 짧은 생각 시간, 자연스러운 자세 차이.
- 지원자 질문: 타이밍·관련성·간결성·경청·주도성. 먼저 묻는 행동을 인정하고 급여·복지 질문 자체를 부정적으로 평가하지 않는다.
- 호감/비호감·좋음/주의: 심사관 관점의 해석 후보이며 인격 등급이 아니다. 관찰 근거·상황·대안 해석·개선 행동으로 설명해야 한다.
- 원문 R1–R8: 단일 행동 감점 금지, 반복성, 맥락, 형식별 검토, 내용 우선, 능동 질문 인정, 근거 제시, 추정 제한.
- 형식 후보: 구조화 다대일, 대화형 1:1, 경력직 실무, 임원, 화상, 비대면 녹화. 회사 규모만으로 실제 전형을 단정하지 않음.

## 지속 확장 원칙

새 기준은 ID/출처/관찰 근거/맥락/긍정·개선·중립·미평가/예외/필요 매체/테스트 사례를 갖춰야 한다. 단순 키워드 감점이나 주관적 인상 누적을 피한다.
제안 → 초안 → 고정 테스트 답변 비교 → 사람 검토 → 승인 → 운영 버전 → 회귀 검증·롤백 순서. 현재 구현은 제안·로컬 초안 단계까지만 지원한다.
