## 핵심 결론

MOOA Resume은 단순한 AI 첨삭기가 아니라 공고, 지원서 전체, 사용자의 검증된 경험을 연결하는 한국어 취업 지원 워크플로우다. 모델 자체보다 반복 입력을 줄이고, 문항 간 경험 중복과 공고 적합성을 한 번에 검토하며, 부족한 사실은 지어내지 않고 질문하는 제품 경험이 차별점이다.

## 대화에서 확정된 제품 방향

1. 지원서 한 문장이 아니라 하나의 `ApplicationCase` 전체를 분석한다.
2. 공고 요구역량을 추출하고 사용자의 실제 경험과 연결한다.
3. 같은 경험의 문항 간 중복, 자료 간 모순, 부족한 근거를 표시한다.
4. AI가 성과나 수치를 만들어내지 않는다. 정보가 없으면 추가 질문 또는 확인 필요 상태로 남긴다.
5. 결과 첫 화면에는 가장 중요한 개선점 3개와 근거를 먼저 보여준다.
6. 사용자의 원래 말투와 사실을 보존하면서 Before/After를 제공한다.
7. 합격 확률, AI 탐지 회피, 과도한 점수 게임화를 제품 메시지로 사용하지 않는다.
8. 초기에는 QUICK/PRO 분석에 집중하고 인간 전문가 검토, 마켓플레이스, 대학 B2B는 데이터 경계만 고려한다.

## 초기 화면 범위

- 전문적이고 신뢰감 있는 한국어 랜딩
- QUICK/PRO 선택이 명확한 분석 입력
- 텍스트 입력과 파일 업로드 진입점
- 분석 과정의 투명한 로딩 상태
- 준비도, 핵심 3개 이슈, 근거, Before/After, 확인 필요 정보가 있는 결과 화면
- 모바일 우선 반응형과 점진적 정보 공개
