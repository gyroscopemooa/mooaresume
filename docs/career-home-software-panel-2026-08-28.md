# [워크트리 초안 · feature/codex-plan] 커리어 홈 단일 소프트웨어 패널

상태: **`/career` 홈 전용 — main 미통합**.

## 사용자 정정

기존의 커리어 홈 기능을 밝은 랜딩과 별도 대시보드로 나누는 것이 아니라, `/career/lab/dashboard`의 중앙 소프트웨어 패널 안에 모두 넣는다.

## 적용

- 바깥 히어로·소개 섹션·별도 시안 배경 제거
- 화면 전체를 하나의 커리어 워크스페이스로 사용
- 워크스페이스 안에 검사 3개, 종합 프로필, 자소서 연결을 실제 링크로 제공
- 개인별 그래프는 로그인 프로필(`/career/profile`)에만 유지

## 유지

검사 문항·채점·결과·로그인 대시보드 동작은 바꾸지 않는다.
