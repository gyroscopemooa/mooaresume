# 커리어 프로필 계정 저장 연결 체크포인트

작성일: 2026-08-27

## 목적

완료한 업무성향·직업흥미·직업가치 탐색 응답을 사용자의 로그인 계정에 저장하는 화면을 추가한다. 이 기능은 AI 호출, 진단, 채용 결과 예측을 하지 않는다.

## 구현 범위

- 새 경로: `/career/profile/save`
- 브라우저에 임시 보관된 완료 응답만 읽는다.
- 기존 인증 클라이언트로 로그인 여부를 확인한다.
- 기존 `POST /api/career-assessments`를 통해 서버에서 점수를 다시 계산해 저장한다.
- 원격 Supabase migration이 적용되지 않은 경우 저장 실패를 일반 오류로 숨기지 않고 준비 중 안내로 바꾼다.

## 보호 및 연동

- 메인 브랜치의 로그인·헤더 구현을 수정하거나 복제하지 않는다.
- 기존 종합 프로필 화면은 변경하지 않아, 통합 시 한 줄의 링크/버튼만 선택적으로 추가하면 된다.
- 실제 원격 migration 적용과 배포는 사용자 승인이 필요하다.

## 검증 예정

- TypeScript, ESLint, 저장 경로의 로컬 렌더 확인.
- 로그인된 계정 + migration 적용 환경에서 실제 저장은 원격 DB 변경 승인 후 검증한다.
