# 커리어 검사 V1 ↔ V2 정합성 및 통합 기준

작성일: 2026-08-27

## 문서 역할

V1 문서(`mooa-resume-career-assessment.md`, `career-assessment-roadmap.md`)는 방법론·안전 경계의 기준이다. V2는 결과 경험과 디자인 언어를 보강한다. 충돌하면 안전·저작권·현재 구현 원칙을 우선한다.

| 주제 | V1 기준 | V2 보강 | 통합 결정 |
| --- | --- | --- | --- |
| 제품 목적 | 자소서·지원서 분석을 돕는 커리어 탐색 | 검사 결과를 공유하고 싶은 리포트 경험으로 강화 | 유지 |
| RIASEC/가치관 | 라이선스·검증 검토 후 도입 | 자체 베타와 예쁜 결과 UX 제안 | 현재의 자체 베타 고지 유지 |
| AI | 사용자 선택·명시적 실행 후 보조 해설 | 추가 질문을 거치는 대화형 해설 제안 | 현재는 계약·안전 검증만, 외부 호출 보류 |
| 결과 | 업무환경 가설과 경험 질문 | 표지형 리포트, 핵심 축·조합·지원서 연결 | V2 디자인을 별도 시안으로 제작 |
| 심리 플랫폼 | 미래 별도 서비스 | 검사 허브·전문가 연결 장기 구상 | 현재 MVP에서 제외 |
| 커뮤니티/라운지 | 후순위 검토 | 취업·진로 라운지 제안 | 지금 구현하지 않음 |
| 가격/유료 | 아직 미결정 | 무료 기본 결과 + 유료 심층해설 아이디어 | 가격·결제·유료 AI는 검증 후 별도 결정 |

## 현재 구현과의 차이

현재 `/career`는 최소 카드형 탐색, 한 문항씩 진행, 점수·차트 중심 결과를 제공한다. V2는 이를 즉시 대체하지 않고 다음 독립 시안으로 검증한다.

1. 검사 선택: 인덱스/포스터형 목록
2. 검사 실시: 카드가 아닌 면(plane) 위의 응답 시트
3. 결과: 대시보드가 아닌 세로형 리포트
4. 공유: 나중에 별도 생성 기능으로 분리

## 통합 전 확인 항목

- 모바일에서 44px 이상의 조작 영역과 키보드 선택이 유지되는가
- IPIP·자체 베타 고지, 비진단성, 결과 저장 안내가 누락되지 않는가
- 결과 디자인이 점수를 채용 예측·적합 판정처럼 보이게 만들지 않는가
- 메인 브랜치의 로그인·헤더 변경과 같은 파일을 덮어쓰지 않는가
- 새로운 라이브러리 없이 CSS/현재 의존성으로 구현 가능한가
