# 무료 멘토 연결 참여 희망 모집

- 사용자 결정: 프리랜서 채용과 별개. 현재는 무료 멘토 연결의 수요·참여 희망자 풀을 모은다. 직무뿐 아니라 꿈, 경험, 일상 대화도 받는다. 운영자가 적합한 상대를 찾았을 때 양쪽 의사를 확인한다. 일정·연결을 보장하지 않는다.
- 현재 범위: 앱 홍보배너 아래 별도 배너, `/mentors` 소개·두 유형 신청, 비공개 기록, `/meensoo/mentor-pool` 운영 목록·검색·분류·유사 분야 후보·상태/메모. 기존 프리랜서 모집은 수정하지 않는다.
- 자동 분류는 선택한 분야 및 자유기술의 키워드 근거를 표시하는 규칙 기반 보조다. AI 평가, 적합도 점수, 자동 연락·매칭은 없다. 원문을 보존하며 운영자가 최종 판단한다.
- 신규 테이블 필요: `mentor_pool_applications`는 일반 문의/유료 전문가 모집과 다른 동의 목적 및 필드를 가진 현재 신청 기록. `mentor_pool_rate_limits`는 비회원 접수의 분산 요청 제한에 필요하다. 공개 프로필·결제·채팅·매칭 테이블은 없다.
- 개인정보: 이메일·이름·자유기술·희망 분야/방식/지역만 저장. 원본 이력서, 민감정보, 연락처 공개 없음. 서버 전용 권한/RLS 및 관리자 인증. 수집 목적은 이번 무료 프로그램 모집·연결 연락이며 유료 상품 마케팅 동의가 아니다. 신청 시 1년 보관 고지, 만료 기록은 매일 정리. 철회는 신청 이메일로 support@mooaresume.com에 요청하고 운영자가 본인 확인 후 삭제.
- 배포 전: 신규 SQL만 검토·적용(pg_cron 기존 설치 필요), 서버 비밀키/관리자 인증 확인, 실제 이메일 연락 및 철회 운영 담당 확인. 운영 배포/원격 SQL/실제 신청자 연락은 이 로컬 개발 범위에 없다.
- 기존 전역 Clarity 스크립트 때문에 새 신청폼·관리자 목록은 `data-clarity-mask="True"`로 명시 마스킹한다. 근거: https://learn.microsoft.com/en-us/clarity/setup-and-installation/clarity-masking . 기존 추적 설정 전체 변경은 본 작업 범위 밖이다.
- 롤백: 홈의 import/배너 1개 및 관리자 메뉴 1개 제거 후 신규 경로를 비활성화. 실제 접수 후 테이블을 삭제하지 말고 먼저 접수 중지·보관/철회 절차를 결정한다.

## 로컬 검증 결과

- 신규 30테스트, TypeScript, 대상 ESLint 통과.
- PGlite SQL 검증: 익명·일반 회원의 직접 접근/저장 차단, 중복 접수 방지, 요청 제한, 수정 충돌, 만료 정리 통과.
- 브라우저: 홈 앱 배너 아래 배치, 두 신청 유형 전환 및 연결, PC/390px 화면 확인.
- 전체 회귀: 2428개 통과, 기존 테스트 5개 실패 및 Expo/Supabase 테스트 환경 오류. 기존 실패 파일은 변경하지 않음.
- 운영 DB migration과 배포 미실행. 로컬 미리보기는 화면 검토용이며 실제 신청 저장 환경은 연결하지 않았다.
- 관리자는 최근 미만료 500건 범위에서 검색/후보를 검토한다. 키워드가 없는 새로운 분야와 부정문/문맥은 자동 해석하지 않으며 원문을 확인해야 한다. 규모가 커지면 서버 검색·페이지 분할과 검증된 분류를 후속으로 확장한다.
- 실제 수락/만남·연락은 운영자 수동. 같은 이메일의 새로운 신청을 임의로 기존 기록에 덮어쓰지 않는다. 동일 전송 재시도만 식별자로 중복 방지한다.
