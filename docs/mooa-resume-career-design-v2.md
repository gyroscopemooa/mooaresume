# 커리어 검사 디자인 V2 — Assessment Lab 시안 명세

## 디자인 원칙

`차갑고 정밀한 연구소 50% + 인간적인 Editorial 30% + 절제된 미래적 인터랙션 20%`

목표는 AI SaaS처럼 보이는 카드 대시보드가 아니라, 신뢰할 수 있는 현대적 측정·개인 리포트 경험이다.

## 시각 토큰

- 배경: warm off-white / 잉크에 가까운 검정
- 포인트: MOOA의 기존 초록을 제한적으로 사용
- 구조: 얇은 규칙선, 넓은 여백, 명시적 순번, 모노 계열 보조 정보
- 타입: 큰 산세리프 제목 + 리포트 섹션의 serif 보조 위계
- 모션: 결과 섹션의 아주 짧은 등장만; 진행 중 AI·로딩 연출 금지

## 화면 명세

### 1. Assessment Index

- 좌측: `ASSESSMENTS / 03`, 01~03 인덱스, 상태(AVAILABLE/BETA)
- 우측: 선택된 검사의 대형 코드와 한 문장 설명
- 카드가 필요하면 하나의 균일한 카드 그리드가 아니라, 각 검사 코드·패턴·정보 밀도가 다르게 보이게 한다.

### 2. Assessment Sheet

- 헤더: 검사 코드, 정식·보조 명칭, `07 / 30`, 진행선
- 질문: 큰 질문 문장, 1~5 수치 응답, 양 끝 라벨
- 데스크톱: 한 화면 1~3문항. 모바일: 1문항 또는 3~5문항 묶음 중 실제 읽기 테스트 후 선택
- 중요한 동작: 이전/다음, 현재 저장 여부, 응답 누락 안내

### 3. Editorial Result

1. 리포트 표지 — `YOUR CAREER PROFILE`, 핵심 코드/문장, 날짜
2. 핵심 축 — 상위 2~3개를 큰 타입과 짧은 문장으로
3. 조합 읽기 — 두 축이 함께 나타날 때의 **가설**, 근거 표시
4. 전체 분포 — 막대·점·선 기반, 레이더는 상세 영역에만 선택 사용
5. 실제 경험 질문 — 자소서에 없는 사실을 만들지 않는 질문
6. 지원서·공고 연결 — 선택형 CTA
7. 한계 및 방법론 — 비진단·비예측·베타 고지

## 이번 시안의 수용 기준

- 첫 화면에서 카드 3개/레이더 차트보다 검사 코드·핵심 문장이 먼저 보인다.
- 결과는 충분한 텍스트 위계가 있는 세로형 한 문서처럼 읽힌다.
- 색·아이콘을 제거해도 구조와 점수 우선순위를 읽을 수 있다.
- 기존 커리어 검사 데이터·채점 로직을 바꾸지 않는다.
- 기존 경로 교체 전 별도 `/career/lab` 시안에서 사용자 확인을 받는다.
