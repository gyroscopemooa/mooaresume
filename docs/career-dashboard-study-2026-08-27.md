# [워크트리 초안 · feature/codex-plan] 커리어 대시보드 레퍼런스 시안

상태: **독립 디자인 시안 — main 미통합**. 경로: `/career/lab/dashboard`.

## 출발점

사용자가 제공한 Harvey 모바일 스크린샷의 구성을 참고했다. 이는 복제 대상이 아니라 다음의 시각 원리를 참고하는 용도다.

- 오프화이트 배경과 검정에 가까운 텍스트
- 큰 serif 헤드라인과 절제된 녹색 포인트
- 여백이 큰 랜딩 뒤 실제 제품 화면을 하나의 신뢰 근거로 제시
- 제품 대시보드는 얇은 테두리, 작은 지표, 막대 그래프, 제한된 카드만 사용

## 무아레쥬메 적용

대시보드 미리보기는 실제 사용자 데이터를 꾸미거나 결과를 예측하지 않는다. 예시 데이터라는 고지를 포함하며, 통합 시에는 로그인한 사용자의 저장된 커리어 결과만 연결한다.

## 기존 Lab 시안과의 관계

- `/career/lab`: Editorial/Assessment Lab 방향
- `/career/lab/dashboard`: Harvey식 랜딩 + 제품 대시보드 미리보기 방향

둘 다 비교용이다. 사용자 선택 전 기존 `/career`는 바꾸지 않는다.
