## 실제 VLM 실행 기록

- 입력: 현재 브라우저 메모리에 있던 약 22초 답변 영상의 20%·50%·80% 시점 JPEG(최대 긴 변 768px).
- q4f16 첫 실행: `vision_encoder_q4f16.onnx` 다운로드 진행을 확인했으나 생성 답변 없이 프롬프트만 디코딩됐다. 초기 파서가 프롬프트 선택지를 결과로 읽은 오탐을 발견해, 생성 토큰 전용 스트리머와 구조 검증으로 수정했다.
- q4 재실행 출력 예: `This is a question for a user who has been looking for this for a long time.`, `The question asks what what ...`, `The question is asking for a description of the image.`
- 판정: 실제 이미지 추론 호출은 연결됐으나 목적 항목 성능은 부족하다. 세 프레임 모두 구조화 항목을 `uncertain`으로 보류한다. 이 결과는 출시 피드백이 아니다.

## 한국어 실제 검증에 필요한 자료

같은 성인 한국어 화자가 같은 1~2문장을 다음 네 방식으로 각 3회 녹음한 WAV/무손실 원본이 필요하다. 각 파일은 10초 안팎이며 자동 이득/노이즈 억제 설정을 함께 기록한다.

1. 작지만 사람이 듣기에 또렷한 발화
2. 사람이 표시한 특정 끝음절이 불명료한 발화
3. 마지막 구절을 실제로 급하게 끝낸 발화
4. 정상적인 문장 마무리

사람 검수표에는 파일별 `문제 없음/있음`, 문제 단어·음절, 시작/끝 시각, 두 명 이상 청자의 합의 여부가 필요하다. 사용자 제공 전에는 합성음성만으로 완료 판정하지 않는다.

## 실행 경계

- 개발 PC: KOMOS Python/ONNX CPU 실행기는 설치됐지만 가중치와 실제 자료 실행은 남았다. 원본 파일은 명시적으로 지정한 로컬 경로만 읽는다.
- 고객 브라우저: KOMOS 경로 없음. 브라우저 로컬 구현 완료로 표시하지 않는다.
- VLM: 고객 기본 기능이 아니라 개발용 선택 실행이다. 공개 모델 가중치를 내려받지만 프레임을 외부 추론 API에 전송하지 않는다.
- 유료 API, 기존 고객 자료 외부 전송, 운영 배포는 수행하지 않았다.
