# 커리어 탐색 도구 검증·출시 계획

## 현재 공개 범위

- 업무성향: IPIP Big Five 공개 문항의 한국어 번안 기반 자기이해 도구
- 직업흥미: RIASEC/Holland 여섯 활동 영역을 참고한 무아 자체 문항 베타
- 직업가치: 직업가치 카드 정리 도구

직업흥미와 직업가치는 표준화 검사, 채용 판정, 직업 적합성 보증으로 표현하지 않는다.

## 베타 검증 순서

1. 한국어 문항 이해도 인터뷰와 인지 면접
2. 역번역 및 직업상담·측정 전문가 검토
3. 파일럿 응답에서 문항 누락·편향·점수 분포·내적 일관성 점검
4. 결과 문구가 직업 추천이나 합격 예측으로 읽히지 않는 UX 검토
5. 수정 이력·검증 결과·한계를 문서화한 뒤에만 외부 홍보 확대

## O*NET 참고 시의 경계

O*NET Interest Profiler 및 Work Importance Locator 원문·번역·점수 규칙을 제품에 복제하거나 번안할 때는 O*NET Career Exploration Tools Content License와 Tools Developer License의 출처 표기, 수정 고지, 검증 요구를 따른다. 현재 베타는 원문 문항을 포함하지 않는다.

## 로그인·AI 해설

검사 응답은 로그인 전 현재 브라우저에서만 임시 보관한다. 계정 저장은 별도 Supabase migration 적용 후 제공한다. AI 해설은 사용자가 문서와 목적을 선택하고 실행할 때만 호출하며, 이력서·자기소개서의 사실을 만들거나 합격 확률을 제공하지 않는다.
