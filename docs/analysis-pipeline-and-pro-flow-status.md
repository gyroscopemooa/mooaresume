# MOOA Resume 분석 파이프라인과 PRO 유형별 흐름

작성일: 2026-08-16

## 현재 가격 기준

- QUICK: 4,900원
- PRO: 9,900원
- FINAL: 14,900원, 추후 출시

현재 루트 명세에는 99,000원 상품이 없다. 9,900원을 잘못 표기한 것이 아니라면 과거 대화에서 검토한 별도 고가안이며 현재 제품 가격에는 반영하지 않는다.

FINAL 14,900원은 BUILD 또는 POLISH용 별도 PRO가 아니다. PRO 전체 기능에 인터랙티브 AI 모의면접, 꼬리질문, 답변 평가와 재훈련을 더하는 미래 상위 상품이다.

## 같은 PRO 가격을 쓰는 이유

PRO는 메시지 수나 작성 상태를 판매하지 않고 하나의 ApplicationCase, 즉 기업·직무·채용공고 기준 지원서 1건을 완성하는 상품이다.

CREATE, BUILD, POLISH는 서로 다른 상품이 아니라 같은 PRO의 시작 위치다.

## 유형별 PRO 흐름

### CREATE + PRO

- 공고 분석
- 경험 후보 탐색
- 사용할 소재 선택
- 부족한 사실만 구조화해 질문
- 개요 확인
- 초안 생성
- 수정
- 전체 문항 교차검수
- 최종본과 면접 준비

### BUILD + PRO

- 현재 초안 분석
- 공고와 초안 사이의 부족한 근거 탐색
- 이력서·경력자료에서 사용 가능한 경험 추천
- 빠진 역할·행동·결과만 질문
- 기존 문장을 보존하면서 내용 강화
- 문항 간 중복과 자료 충돌 확인
- 최종본과 면접 예상질문

### POLISH + PRO

- 완성본과 제출 조건 확인
- 공고·이력서·경력자료 교차검증
- 문항 충족, 글자 수, 맞춤법, 표현 점검
- 경험 중복과 사실 충돌 확인
- 긴 경험 인터뷰 없이 최소 수정
- 최종 제출본과 면접 리스크

BUILD와 POLISH는 입력 자료가 비슷하지만 처리 단계가 다르다. BUILD는 부족한 내용을 찾아 질문하고 보완하며, POLISH는 현재 내용을 최대한 보존하고 바로 검수한다.

## 분석 파이프라인 현재 구현

- QUICK과 PRO 공통 AnalysisRequest Zod 계약
- ResumeAnalysisProvider 인터페이스
- 실제 AI 연결 전 검증용 MockAnalysisProvider
- QUICK과 PRO 입력 내용을 게스트 세션에 저장
- 분석 시작 전 자료·가격·제공 범위를 확인하는 /analysis/prepare
- 로그인·결제 전에는 서버 저장과 AI 호출을 하지 않음
- 결과 화면 샘플과 실제 분석 시작 버튼을 명확히 분리

Mock provider 결과는 실제 분석으로 제공하지 않는다. 실제 출시에서는 서버의 OpenAI Responses API adapter가 같은 인터페이스로 ResultDocument를 반환하도록 연결한다.
