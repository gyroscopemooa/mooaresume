# 무아레쥬메와 심리 플랫폼의 관계

작성일: 2026-08-26

두 서비스는 사용자 문제, 데이터 민감도, 책임 범위가 다르므로 한 제품으로 합치지 않는다.

| 구분 | 무아레쥬메 | 미래 심리 플랫폼 |
| --- | --- | --- |
| 현재 목적 | 취업 준비·지원서 개선 | 심리 자가점검·전문가 연결·변화 관리 |
| 현재 검사 | 업무성향 자기이해 | 별도 기획, 아직 미구현 |
| 위험 데이터 | 지원서·경력 정보 | 건강·상담·임상 관련 민감정보 가능 |
| 결과 표현 | 경험 선택을 돕는 커리어 단서 | 진단이 아닌 자가점검 및 전문가 연결 |
| 구현 시점 | 지금 | 별도 서비스로 나중에 |

## 자연스러운 연결 원칙

무아레쥬메의 사용자는 업무성향을 통해 실제 경험과 지원 직무를 더 잘 설명할 수 있다. 심리 플랫폼의 사용자는 정신건강·상담 요구를 다룬다. 전자는 후자의 유입 퍼널이나 민감정보 수집 실험으로 쓰지 않는다.

두 제품이 나중에 함께 존재하더라도 다음을 지킨다.

- 계정·동의·결과 데이터는 목적별로 분리한다.
- 심리 플랫폼 결과를 취업 평가나 채용 추천에 사용하지 않는다.
- 무아레쥬메의 커리어 검사 결과를 심리 상태로 해석하지 않는다.
- 어떤 교차 공유든 사용자의 명시적이고 목적별인 동의가 선행되어야 한다.

현재의 실질적인 연결은 제품 데이터 공유가 아니라 운영 경험이다. 무아레쥬메에서 개인정보 보호, 동의, 결제, 결과 전달, 사용자 지원을 안정적으로 운영한 경험을 미래 심리 플랫폼의 기반 역량으로 축적한다.
