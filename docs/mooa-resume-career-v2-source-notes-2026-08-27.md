## V2에서 추가된 제품 관점

무아레쥬메의 검사는 독립 심리진단 서비스가 아니라, 취업 준비자가 자신의 경험·업무 환경 선호·직무 탐색 언어를 정리하도록 돕는 무료 유입 및 전환 기능이다.

`검사 → 기본 결과 → 종합 커리어 프로필 → 이력서·자소서·공고와의 사용자 선택형 연결`

장기적으로 별도 Assessment 사업 가능성을 탐색할 수 있으나, 상담 중개·정신건강 검사·전문가 마켓플레이스는 현재 MVP에 포함하지 않는다.

## 대화에서 보강된 커리어 검사 원칙

- 결과는 숫자 나열이 아니라 **무슨 활동·환경에서 몰입하는지**를 설명하고, 실제 경험을 되짚는 질문으로 이어진다.
- `추천 직업 확정`, 합격 가능성, 직무 적합 확률, 임상·정신건강 진단은 제공하지 않는다.
- RIASEC·Big Five·가치관은 각각 다른 관점이며, 종합 화면에서만 교차 단서로 읽는다.
- AI는 무료 채점이나 기본 결과에 쓰지 않는다. 사용자가 로그인하고 자료를 직접 선택한 경우에만, 검사 결과의 애매한 지점을 질문하는 보조 해설 후보가 된다.
- AI 해설의 가치는 긴 결과문 재작성보다 `검사 → 추가 질문 → 사용자의 답 → 수정된 가설 → 지원서·공고 연결` 흐름에 있다.
- 공개·제휴·자체 개발 척도는 구분한다. 타 척도 원문, 한국어 번역, 규준, 진단·자격 제한을 복제하지 않는다.

## V2 디자인 방향

한 문장: **Digital Psychometric Lab / Editorial Report**.

| 화면 | 역할 | 의도된 인상 |
| --- | --- | --- |
| 검사 목록 | 플랫폼/아카이브 | 왼쪽 인덱스와 큰 타입, 검사별 고유 심볼·코드 |
| 검사 실시 | 조용한 디지털 검사지 | 카드·그라데이션·AI 장식보다 숫자·선·여백·명확한 응답 척도 |
| 결과 | 한 권의 프리미엄 리포트 | 요약 → 핵심 축 → 조합 → 실제 지원서 적용 순서 |
| 공유 카드 | 개인 리포트 표지 | 1:1 또는 9:16, 결과 전체가 아닌 제한된 핵심 코드·문구 |
| AI 해설 | 결과 이후의 선택 기능 | 검사 실시/기본 결과와 시각적으로 분리 |

### 피할 것

- 동일한 둥근 카드 수십 개, 보라 그라데이션, 반짝이는 AI 아이콘, “AI 분석 중” 장식
- 결과 첫 화면의 레이더 차트·점수 카드 나열
- 병원 전산 화면, MBTI 무료 테스트의 캐릭터·과장 광고 문법
- 아직 제공하지 않는 심리·상담 범위를 커리어 검사에 섞는 것

### 우선 적용할 것

1. 오프화이트 바탕, 거의 검정의 텍스트, 얇은 선, 절제된 초록 포인트
2. 큰 검사 코드(RIASEC / OCEAN), 큰 순번과 점수, serif 보조 타이포의 편집적 위계
3. 결과 상단은 `YOUR CAREER PROFILE` 같은 리포트 표지형 구성
4. 데이터 시각화는 보조 수단으로만 사용하고, 타입 크기·밀도·순서로 우선 표현
5. 접근성: 키보드 응답, 모바일 3~5문항 단위, 색만으로 점수 구분하지 않기

## 참고 레퍼런스의 사용법

원문에 언급된 PrinciplesYou, Dimensional, TraitLab, CareerExplorer, Human Benchmark, Nothing, Aesop, Harvey, Baseframe 등은 **구조·밀도·타이포·전환 감각만** 참고한다. 문구, 그래픽, 코드, 고유 자산을 복제하지 않는다.
