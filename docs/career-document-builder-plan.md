## 1. 무엇

> 이력서, 자기소개서, 자격증, 수료증, 해외 경험, 여행, 그 밖에 지금까지 받은 모든 자료를 넣으면 **직무기술서를 만들어 준다.** 그리고 `심리상담사 쪽으로` 같은 방향을 지정할 수 있게 한다.

지금 제품이 하는 일과 방향이 반대입니다.

```
지금:   자소서가 있다  →  고쳐 준다
이것:   자료만 있다    →  없던 문서를 만들어 준다
```

## 2. 왜 이게 맞는 자리인가

**흩어진 자료를 하나로 모으는 일은 사람이 제일 하기 싫어하고, 기계가 제일 잘합니다.** 자격증 사진, 수료증 PDF, 예전 이력서, 여행 기록이 각각 다른 폴더에 있는 상태에서 "경력기술서 한 장으로 정리"는 반나절짜리 일입니다. 자료를 이미 다 받아 두는 제품에서는 한 번 더 읽는 일입니다.

그리고 **이미 재료가 다 있습니다.** 자료 분류(`document-classify`), 참고자료 예산, 근거 인용 규칙(`evidenceSchema`), 사실 검증(`validator`)이 전부 이 기능이 필요로 하는 것들입니다.

## 3. `+@` 방향 지정

`심리상담사 관련 직무기술서로 만들어줘` 처럼 목표를 주면, **같은 자료에서 다른 문서**가 나옵니다.

- 같은 상담 경험이라도 무엇을 앞에 두고 무엇을 줄일지가 달라집니다.
- 이건 사실을 바꾸는 것이 아니라 **순서와 분량을 바꾸는 것**입니다. 그 선이 지켜지는 한 안전합니다.

## 4. 가장 큰 위험 — 여기가 전부입니다

**없는 경력을 만들어내는 것.** 첨삭은 원문이 있어서 대조할 것이 있지만, 여기는 **원문이 없습니다.** 자료 조각에서 문장을 만드는 일이라 지어내기가 훨씬 쉽습니다.

지켜야 할 규칙(이미 제품에 있는 것들과 같은 규칙입니다):

- 자료에 **적혀 있는 사실만** 씁니다. 자격증 이름에서 업무를 추론하지 않습니다.
- 문장마다 **어느 자료에서 나왔는지** 남깁니다. 근거 없는 문장은 만들지 않습니다.
- 기간·수치는 자료에 있는 그대로. `validator`의 `NEW_NUMBER` 검사가 그대로 적용되어야 합니다.
- 방향 지정(`심리상담사`)이 **없는 경험을 만들어내는 구실이 되면 안 됩니다.** 방향은 배치만 바꿉니다.
- 비어 있는 항목은 채우지 말고 **"자료에서 확인되지 않습니다"**로 남깁니다. 이건 이미 제품의 문장 규칙입니다.

## 5. 정하지 않은 것

| | 질문 |
|---|---|
| 상품 | 별도 상품인가, PRO에 포함인가, 아니면 무료 미끼인가 |
| 가격 | 만들어 주는 일은 첨삭보다 출력이 깁니다. 원가가 다릅니다 |
| 출력 | DOCX·한글에서 열리는 형식이 필요합니다(첨삭은 이미 DOCX를 냅니다) |
| 재사용 | 만든 직무기술서를 그대로 PRO 첨삭의 입력으로 넘길 수 있어야 자연스럽습니다 |
| 경험은행 | [`pro-candidate-materials-and-experience-bank.md`](./pro-candidate-materials-and-experience-bank.md)와 같은 것인가, 그 앞단인가 |

## 6. 혼합 파일 — 별도 카테고리는 만들지 않기로

같은 날 나온 이야기라 여기에 같이 적습니다.

> 이력서와 직무기술서가 한 파일에 들어 있었습니다. `혼합` 카테고리를 만들까?

**만들지 않는 쪽을 권합니다.** 카테고리는 **그 자료를 어떻게 읽을지**를 정하는 값인데, `혼합`은 아무것도 정해 주지 않습니다. "모르겠다"는 이미 `UNSET`이 하고 있고, 그쪽은 진행을 막아서 사용자가 고르게 합니다.

그리고 **본인 서류끼리 섞인 것은 애초에 문제가 아닙니다.**

```
이력서 + 직무기술서   →  둘 다 본인이 쓴 것  →  둘 다 근거로 씀
                        →  무엇으로 고르든 결과가 같습니다
```

**위험한 혼합은 딱 하나, 채용공고가 섞인 경우입니다.**

- `채용공고`로 고르면 → 본인 경력이 근거에서 통째로 빠집니다(2026-08-31에 실제로 터진 사고).
- `이력서`로 고르면 → 회사가 요구한 자격이 본인이 가진 것처럼 쓰일 수 있습니다. **이쪽이 더 나쁩니다.**

이건 카테고리로 풀 수 없습니다. 한 파일 안에 성격이 다른 두 문서가 있으면 **나누는 것 말고는 답이 없습니다.**

**그래서 만든다면 카테고리가 아니라 감지와 안내입니다.** 한 파일에 공고 표지(`자격요건`·`우대사항`·`모집분야`)와 본인 서류 표지(`경력사항`·`지원동기`)가 **둘 다** 있으면 이렇게 말하면 됩니다.

> 이 파일에 채용공고와 본인 서류가 같이 들어 있는 것 같습니다. 나눠서 올리시면 둘 다 제대로 씁니다.

빈도는 낮지만(0.1% 수준) 터졌을 때 손해가 큰 쪽이라, 감지만 해 두는 값은 있습니다. **지금은 하지 않습니다.**
