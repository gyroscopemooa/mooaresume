# 커리어 검사 카탈로그·해석·SEO 로드맵

작성일: 2026-08-26  
상태: 구현 순서 확정 전 설계 기준

## 왜 검사를 하는가

무아레쥬메의 검사는 사람을 한 가지 유형으로 낙인찍거나 채용 결과를 예측하지 않는다. 사용자가 다음 세 가지를 더 잘 하게 만드는 도구다.

1. 지원 직무와 업무환경에 대해 스스로 설명할 언어를 얻는다.
2. 자기소개서에 넣을 **실제 경험**을 더 잘 고른다.
3. 이력·지원공고·검사 결과를 합친 `내 커리어 프로필`을 만든다.

## 검사별 역할

| 사용자명 | 전문·방법명 | 묻는 것 | 결과로 주는 것 | 현재 상태 |
| --- | --- | --- | --- | --- |
| 업무성향 분석 | 50-item IPIP representation of Goldberg (1992) Big-Five markers | 평소의 상호작용·협업·계획·변화·학습 성향 | 업무방식, 강점 탐색 단서, 선호 업무환경, 자소서 경험 질문 | 구현됨 |
| 직업흥미 분석 | RIASEC / Holland 직업흥미 모델 | 어떤 활동·문제·직무 영역에 끌리는지 | R·I·A·S·E·C 관심 영역, 직무·산업 탐색 시작점 | 라이선스·한국어 적용 확인 후 |
| 직업가치 분석 | 공개 사용 가능 척도 선정 또는 전문가 공동 개발 | 직장에서 중요하게 생각하는 조건 | 안정·성장·보상·자율·영향·관계 등 우선순위와 선호 환경 | 도구 선정 전 |
| 종합 커리어 프로필 | 세 검사 + 이력 + 지원공고 | 성향·흥미·가치·실제 경험이 만나는 지점 | 탐색할 직무군, 선호 환경, 지원서 경험 선택, 공고별 확인 질문 | 앞선 검사 후 |

## 현재 업무성향 분석의 해석 범위

### 할 수 있는 해석

- 응답상 두드러진 업무방식과 선호 환경을 설명한다.
- 실제 경험에서 확인할 행동을 질문으로 제안한다.
- 지원 공고의 업무 방식과 비교할 때 확인할 지점을 보여준다.

### 하면 안 되는 해석

- `당신에게 맞는 직업은 하나`라고 단정하기
- 채용 적합도·합격 가능성·성과를 수치로 예측하기
- 임상·정신건강 진단처럼 해석하기
- 실제 이력에 없는 성과·역량을 만들어 자기소개서에 넣기

Big Five만으로는 직업 추천을 확정하지 않는다. 그 대신 `업무환경 가설`을 제공한다. 예: 계획·완수 응답이 높은 경우 "일정·품질 기준·책임 범위가 명확한 업무에서 자신의 방식이 잘 드러날 수 있습니다"처럼 쓴다. 구체적 직무군은 RIASEC와 가치관 결과, 실제 이력 및 지원공고를 함께 본 뒤 제안한다.

## 해석 엔진 순서

### 1차 — 지금 다음 개발

결정적 규칙 기반 해석을 결과 화면에 추가한다.

- 5개 점수의 상·중·하 조합
- 상위 2개 특성이 의미하는 업무방식
- 선호·주의 업무환경
- 자소서에서 찾을 실제 경험 질문
- 지원 직무/공고가 아직 없을 때의 탐색 CTA

모든 문구는 점수와 문항 수에 연결하고, 진단·적합 확률을 만들지 않는다.

### 2차 — AI 개인화 보조

AI는 채점·판정자가 아니다. 결정적으로 계산된 점수와 사용자가 제공한 이력·지원직무·공고만 받는다. Structured Output으로 아래 형식만 반환한다.

- `profile_summary`: 점수 근거를 벗어나지 않는 한 문장
- `work_environment_hypotheses`: 환경 가설과 이유
- `experience_prompts`: 이력에 없는 사실을 만들지 않는 경험 질문
- `job_posting_questions`: 공고와 충돌 또는 확인이 필요한 지점

모든 AI 문장은 입력된 점수 또는 사용자가 제공한 사실에 근거를 연결한다. 모델은 추천직무의 합격확률·심리 진단·새 성과를 말할 수 없다.

### 3차 — 종합 커리어 프로필

RIASEC·가치관·실제 이력·지원공고가 갖춰진 뒤에만 직무군/산업군 탐색을 제공한다. 표기는 `탐색해 볼 직무군`과 `확인할 근거`로 하고, `당신에게 맞는 직업` 또는 적합 확률로 단정하지 않는다.

## SEO 구조

### 공개·색인 페이지

- `/career`: 무료 커리어 검사
- `/career/work-style`: 무료 업무성향 검사 | 나에게 맞는 업무방식 찾기
- 향후 `/career/interest`: 무료 직업흥미 검사 | 나에게 맞는 직무 탐색
- 향후 `/career/values`: 직업가치 분석 | 내가 중요하게 생각하는 일의 조건

`무료 성격검사`는 보조 키워드로 사용 가능하지만, 페이지 제목의 주 키워드는 취업 맥락에 맞는 `업무성향 검사`로 둔다. 첫 화면과 FAQ에 `IPIP Big Five 기반 성격 5요인 평가`를 명확히 적어 검색 의도와 방법론을 모두 충족한다.

### 비공개·noindex 페이지

- 검사 진행 세션
- 개인 결과 화면

개인 결과는 개인정보 가능성과 중복 템플릿 문제 때문에 검색 결과에 노출하지 않는다.

### 전환 연결

- 전체 헤더: `자소서 첨삭 | 커리어 검사 | 가격 | 마이페이지`
- 메인 중단: 업무성향 분석 CTA 1개
- 자소서 시작 전: 선택형 커리어 검사 안내
- 자소서 결과 후: `다음 단계 · 내 커리어 프로필 만들기`
- 검사 결과 후: `내 자기소개서 분석하기`, `지원공고와 비교하기`

## 독자 검사에 대한 결정

`MOOA 업무 운영 방식 체크`를 Big Five와 별개 검사로 바로 만들지 않는다. 두 검사는 현재 범위에서 너무 겹치며, 자체검사를 하나 더 붙여도 정보량보다 혼란이 커진다.

대신 이름은 결과 묶음에 쓴다. 예: `나의 MOOA 업무 운영 방식`은 Big Five·직업흥미·가치관·실제 이력의 **종합 결과 화면 이름**이다. 나중에 독자 척도가 필요해지면, 별도 문항 개발·전문가 내용타당도·파일럿·신뢰도/타당도 검토 후 `연구용 베타`로만 공개한다.

## 구현 우선순위

1. 업무성향 결과의 규칙 기반 해석·CTA 강화
2. 저장용 데이터 모델 및 로그인 사용자 결과 보관
3. 헤더·메인·자소서 전후 CTA, sitemap·메타데이터 완성
4. RIASEC/O*NET 라이선스와 한국어 적용 검토
5. 직업흥미 분석 구현
6. 가치관 도구 선정 및 구현
7. 종합 커리어 프로필과 이력/공고 연계
8. 실제 사용자가 쌓인 뒤 지원자 라운지의 최소 씨앗 기능 검토
