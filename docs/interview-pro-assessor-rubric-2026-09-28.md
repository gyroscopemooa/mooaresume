# 면접 PRO 전체 수행 — 내부 심사·코칭 기준 v2

상태: 내부 기준과 관리자 초안에 적용. 실제 영상/음성/AI 자동 분석 미연결.
이 문서는 회사 공식 채용 기준 또는 검증된 채용 예측 도구가 아니다.
참고 원문: [사용자 제공 전체 수행 기획](interview-pro-full-session-user-reference-2026-09-28.md).
원문의 대학/기관 인용은 출처 링크와 내용을 별도 검증하기 전까지 사실 근거로 채택하지 않는다. 원문 중 ‘채팅 삭제’는 실행 지시가 아니며 타자 응시 계획은 유지한다.

## 수행 흐름

사전 장비 확인·분석 고지 및 동의 → 입장 대기 → 입장·인사 → 착석 → 질문 경청 → 생각·답변 → 후속 질문 → 지원자 질문 → 종료 인사·퇴장 → 복기.
실전에는 정답 동작 안내를 하지 않는다. 학습 모드의 사전 안내와 종료 후 코칭은 별개다. 녹화 시작/종료와 동의 범위를 명확히 표시한다.

## 심사관 관점 평가표

| 영역 | 긍정 관찰 | 개선 검토(부정 판단 후보) | 자동 감점하지 않는 경우 |
|---|---|---|---|
| 입장·착석 | 안내를 확인하고 인사·착석 | 명확한 안내와 충돌해 진행을 방해 | 안내자 동행, 이미 착석, 인사 위치·횟수, 단추·손 위치 |
| 경청 | 질문 요지 확인, 적절한 명료화 | 상대 발언을 반복적으로 끊어 전달 방해 | 통신 지연, 정중한 역질문, 생각하는 침묵 |
| 내용 | 질문 적합성, 본인 행동·결과·직무 연결 | 질문 이탈, 모호한 역할, 확인 필요한 모순 | 수치 부재, 경험 질문 아닌 답변의 STAR 생략 |
| 음성 | 실제 청취 가능한 음량·명료한 흐름 | 이해를 방해하는 반복·말끝 누락 | 사투리, 말투 차이, 장비 품질, 장애, 전사 오류 |
| 자세·동작 | 대화를 방해하지 않는 동작 | 실제 소음·전달 방해를 동반한 반복 행동 | 카메라 사각지대, 자연스러운 제스처·이동, 단추·손·다리 위치 |
| 지원자 질문 | 역할·성과 기준·협업·근로조건 확인 | 설명을 들은 뒤 같은 질문을 맥락 없이 반복 | 먼저 질문함, 급여·휴가 질문, 질문할 것이 없음 |
| 마무리 | 종료 안내 확인·상황에 맞는 감사 | 종료 발언을 반복 방해 | 문구 차이, 기립 불가, 온라인 종료, 영상 누락 |

감점 요청은 우선 ‘개선 검토’로 기록한다. 수치 가중치는 검증 전 미설정이며 임의의 총점/채용가능성은 만들지 않는다. 동일 행동의 중복 감점을 금지한다. 확인 불가를 부정 관찰로 바꾸지 않는다.

## 사용자 스타일 반영

- 안내자와 입장하면 문 앞 또는 면접관 앞에서 ‘안녕하십니까’ 등 상황에 맞게 인사할 수 있다.
- 착석 안내 후 앉는 흐름을 연습하되, 자유롭게 앉도록 안내된 자리에서는 기다림을 강제하지 않는다.
- 정장 단추 정리와 편안한 손 위치는 복장·편의 팁이다. 재킷·캐주얼 복장, 단추 유무로 감점하지 않는다.
- 자기소개 때 ‘반갑습니다’로 이어갈 수 있으나 특정 문구와 반복 인사는 의무가 아니다.
- 소규모 1:1에서는 ‘시간 내주셔서 감사합니다’처럼 자연스럽게 마무리할 수 있다.
- 면접관이 질문 기회를 주지 않아도 ‘마치기 전에 한 가지 여쭤봐도 될까요?’라고 요청하는 것은 적절한 주도성일 수 있다.

## 지원자가 먼저 질문하는 경우

사용자 발화를 answer / clarification / candidate_question / stop_request로 분리하는 엔진이 필요하다. 모호하면 질문인지 확인한다. 질문 발생 자체를 이탈로 채점하지 않는다.
질문 기회 요청 → 면접관 수락 또는 종료시간 안내 → 제공된 기업 자료 내 답변 → 원래 면접으로 복귀 흐름을 구현해야 한다. 회사 내부 정책·급여·채용 결과를 지어내지 않는다.
질문의 관련성, 앞선 설명 반영, 시점·상대 발언 존중을 근거와 함께 코칭한다. 급여·복지·근로조건 질문은 정당한 정보 확인이다.

## 결과 및 타임라인 계약

각 이벤트: 구간 시작/끝, 영역, 관찰 사실, 영상·음성·전사·세션 이벤트 근거, 맥락, 긍정/개선/중립/미평가, 개선 연습.
타임라인 클릭 시 해당 녹화 구간으로 이동하는 UI는 후속 구현이다. 예시 시각·횟수를 실제 측정값처럼 표시하지 않는다.
시선·표정은 선택적 자기 복기 대상으로 두며 자동 점수와 인성·열정·거짓말 추정에서 제외한다. 자세 차이를 신체·정신 상태로 해석하지 않는다.
음성만 있으면 영상 관찰 제외, 타자만 있으면 음성·영상 제외. 전체 능력 점수를 낮추거나 미평가를 0점으로 처리하지 않는다.

## 적용 범위와 남은 작업

- 적용: 7영역 공통 루브릭, 근거·시각·매체 검증 스키마, 관리자 v2 프롬프트 선택 및 기존 v1 보존.
- 미완료: STT, 영상 관찰, 후보자 역질문 인식·응답 엔진, 전체 세션 녹화/입퇴장 모드, 타임라인 탐색, 서버 프롬프트 버전·승인·롤백.
- 출시 전: 동의·삭제·보존기간, 장비별 접근성, 신체·언어 차이에 대한 회귀 평가, 실제 코치의 일치도 검증.
