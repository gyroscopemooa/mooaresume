# 면접 PRO 제품 경계 및 영상·음성 실전 모의면접 계획

작성일: 2026-09-28
상태: 제품 방향 확정용 문서. 이 문서 작성으로 런타임 코드·DB·결제·배포는 변경하지 않는다.

관련 상세 전략: [기업 AI 채용전형 대비 전략](./interview-pro-ai-hiring-strategy-2026-09-28.md)
구현 할 일: [면접 PRO V2 구현 TODO](./interview-pro-v2-implementation-todo-2026-09-28.md)
`기업 AI 채용전형 대비`는 부가 기능이 아니라 일반·대면 실전훈련과 동급인 면접 PRO의 전면 축으로 본다.

## 1. 결론

면접 PRO를 단순히 `현재 FINAL 면접 기능 + 카메라·마이크`로 만들면 안 된다.
그 구조에서는 사용자가 느끼는 차이가 영상·음성 버튼 하나뿐이고, 별도 상품을 살 이유가 약하다.

권장 구분은 다음과 같다.

- **PRO:** 지원서에서 실제로 나올 질문과 위험을 찾는 단계
- **FINAL:** 한 지원 건의 답변을 만들고 기본 모의면접까지 끝내는 단계
- **면접 PRO:** 여러 번 말하고, 다시 보고, 약점을 반복 훈련하는 독립 면접 훈련 제품

면접 PRO는 현재 면접 준비팩과 모의면접 기능을 모두 포함하되, 차별점은 카메라 자체가 아니라
`반복 훈련·면접 유형·녹화 복기·세션 비교·약점 재훈련`까지 이어지는 훈련 시스템이어야 한다.

### 모바일은 축소판이 아니라 주요 응시 환경

면접 PRO는 PC 우선 화면을 휴대폰 폭에 맞춰 줄이는 제품으로 만들지 않는다. 휴대폰은 카메라·마이크가
이미 준비돼 있고 사용자가 장소를 옮겨 짧게 반복 연습하기 쉬우므로, 실제 이용 비중이 높을 수 있는 1급
클라이언트로 본다.

- 전형 선택과 설정은 한 손 엄지로 누를 수 있는 최소 44~48px 조작 영역을 사용한다.
- 입력 필드는 iOS 자동 확대를 막는 16px 이상을 기본으로 하고, 키보드가 올라와도 주요 CTA가 가려지지 않게 한다.
- 세로 응시에서는 셀프뷰, 질문, 타이머, 녹화 버튼이 서로 가리지 않도록 순서를 고정한다.
- 실전 중에는 하단 탐색을 숨기고 녹화 종료·다음 문항 같은 현재 행동만 남겨 오조작을 줄인다.
- 준비·녹화 중에는 지원 브라우저에서 Screen Wake Lock을 요청하되, 거부돼도 면접은 정상 진행한다.
- 노치·홈 인디케이터 safe area, `dvh/svh`, 가로 회전, 큰 글자, 터치 피드백을 출시 전 실기기에서 검증한다.
- 시각 스타일은 토스처럼 정보 위계가 분명하고 터치 반응이 빠른 모바일 제품을 참고하되, 장식보다 응시 집중과
  신뢰를 우선한다.

## 2. 확인한 현재 구현 상태

### 현재 기본 브랜치 계열에 있는 기능

- PRO·FINAL: 지원자료 기반 예상질문, 질문 이유, 답변 핵심포인트, 면접 리스크
- FINAL: 텍스트 모의면접, 답변별 강점·부족한 점, 동적 꼬리질문, 최종 리포트, 약점 재연습
- 모의면접 세션·턴·실패 횟수·리포트·추가 재시도 이용권 저장

### `feat/final-interview-pack`에 구현된 기능

- 30초 자기소개와 1분 자기소개
- 지원동기, 직무 지원동기, 입사 후 포부 등 총 11개 답변 슬롯
- 문항별 `만들 수 있음 / 자료 보완 필요 / 내용 확인 필요` 판정
- 원문 문서·버전·문단으로 연결되는 근거 보기
- 핵심 키워드, 말하는 순서, 한 줄 기억 요약, 예상 꼬리질문
- `전체 답변 → 핵심 문장 → 키워드만 → 힌트 없이 말하기` 4단계 연습
- 사용자 수동 타이머, 직접 수정, 선택 답변 AI 수정, 이전 버전 복원
- 관리자 무결제 FINAL 테스트 A/B/C

변경 기록상 실제 서비스 DB·로그인 계정·실제 AI로 기능 검증까지 했지만,
이 브랜치는 아직 `origin/main`에 병합되지 않았고 일반 공개·Cloudflare 동작은 검증하지 않았다.

### 아직 없는 것

- 마이크 녹음과 STT
- 질문 TTS
- 카메라 셀프뷰·녹화·재생
- 음성 답변 시간·반복어·침묵 등 객관 지표
- 준비팩에서 고른 답변·꼬리질문을 모의면접 세션으로 직접 넘기는 연결
- 세션 간 전후 비교와 장기 연습 기록

## 3. 상품별 권장 범위

| 상품 | 사용자가 사는 목적 | 제공 범위 |
| --- | --- | --- |
| QUICK | 이미 쓴 문장을 빠르게 고침 | 면접 기능 없음. 필요하면 잠긴 예시나 다음 단계 안내만 제공 |
| PRO | 내 지원서에서 무엇을 물을지 확인 | 예상질문, 질문 이유, 답변 핵심포인트, 면접 리스크, 자료 근거 |
| FINAL | 이 지원 건의 답변을 준비하고 기본 연습까지 완료 | PRO 전체 + 30초·1분 답변 준비팩 + 키워드 암기 + 현재의 제한된 텍스트 모의면접 |
| 면접 PRO | 실제 면접처럼 여러 번 말하고 약점을 훈련 | 기존 면접 기능 전체 + 영상·음성 실전 모의면접 + 반복 세션 + 유형별 훈련 + 녹화 복기 + 세션 비교 |

### PRO에서 유지할 것

PRO의 예상질문·면접 리스크·답변 핵심포인트는 지원서 분석의 자연스러운 결과이므로 빼지 않는다.
다만 30초·1분 완성 답변과 전체 암기팩까지 PRO에 모두 주면 FINAL 경계가 약해지므로 넣지 않는다.

### FINAL에서 유지할 것

30초·1분 자기소개, 지원동기·포부, 근거, 키워드 암기와 현재 텍스트 모의면접은 유지한다.
이를 빼면 FINAL은 PRO와 차이가 크게 줄고, `자소서에서 면접까지`라는 제품 약속도 끊긴다.

FINAL은 **한 지원 건을 면접 직전까지 정리하는 완결 상품**으로 둔다. 반복 훈련의 깊이와 횟수는
면접 PRO보다 제한한다. 영상·음성 기능을 FINAL에 맛보기로 넣는다면 짧은 기본 세션 1회 정도로 제한하고,
정확한 횟수와 가격은 실제 AI·STT 비용 측정 뒤 결정한다.

### 면접 PRO에 추가할 차별점

1. **독립 진입**
   - FINAL 구매 없이도 이력서·자소서·채용공고를 넣고 시작할 수 있다.
   - 기존 PRO·FINAL 사용자는 같은 `ApplicationCase`와 `SubmissionSnapshot`을 다시 업로드하지 않고 가져온다.

2. **영상·음성 실전 세션**
   - AI 질문 음성 재생(TTS)
   - 사용자 마이크 녹음과 STT
   - 카메라 셀프뷰 및 로컬 녹화·재생
   - 텍스트 입력으로 전환 가능한 대체 경로

3. **면접 유형별 훈련**
   - 30초·1분 자기소개 집중
   - 지원동기·입사 후 포부
   - 경험·성과 검증
   - 직무·회사 맞춤
   - 압박·동적 꼬리질문
   - 약점 문항 집중 재훈련

4. **반복 훈련 과정**
   - 한 번 답하고 끝나는 것이 아니라 `실전 세션 → 리포트 → 약점 선택 → 재연습 → 다시 실전`으로 이어진다.
   - 같은 질문을 외워 읽는 것만 방지하도록 표현을 바꾼 변형 질문을 제공하되, 자료에 없는 사실은 만들지 않는다.

5. **녹화 복기와 객관 지표**
   - 실제 답변 시간
   - 말한 분량과 말하기 속도
   - 반복어·군더더기 표현
   - 긴 침묵 구간
   - 질문 핵심에 답했는지
   - 준비팩의 근거와 다른 주장 또는 확인되지 않은 수치

6. **세션 이력과 전후 비교**
   - 세션별 질문·음성·전사문·평가·사용 자료 버전을 묶어 저장한다.
   - 첫 시도와 재시도의 답변 구조, 시간, 반복어, 근거 충실도를 비교한다.
   - 합격 가능성이나 자신감 점수는 만들지 않는다.

따라서 면접 PRO의 판매 문장은 `카메라가 켜지는 면접`이 아니라 다음처럼 잡는다.

> 준비한 답변을 실제로 말하고, 녹화로 다시 보고, 약한 질문을 반복해서 훈련하는 면접 연습 과정

## 4. 영상 기능의 경계

첫 버전에서 카메라는 **평가 센서가 아니라 실전 분위기와 자기 복기 도구**다.

- 사용자가 버튼을 눌러야만 권한을 요청하고 녹화를 시작한다.
- 페이지 진입·탭 전환만으로 자동 녹음하지 않는다.
- 가능하면 영상은 서버에 올리지 않고 브라우저 안에서 셀프뷰와 재생에 사용한다.
- 서버에는 음성 또는 전사문만 보내는 구조를 우선한다.
- 카메라·마이크를 거부해도 텍스트 모의면접을 계속 사용할 수 있어야 한다.
- 영상 저장이 필요해지면 저장 여부·보관기간·삭제 시점에 별도 동의를 받는다.

초기 범위에서 제외한다.

- 얼굴 표정 점수
- 시선 점수
- 외모·자세 점수
- `자신감 72점` 같은 근거 약한 수치
- 실시간 생성형 AI 아바타(초기 출시에서는 제외하고, 면접관 존재감을 주는 정적 인물·TTS·사전 제작 영상 루프는 허용)
- WebRTC 화상통화

## 5. 권장 사용자 흐름

### FINAL 사용자

```text
FINAL 결과
→ 면접 준비팩
→ 30초·1분 및 주요 답변 작성
→ 키워드 연습
→ 답변 카드의 ‘실전 연습에 보내기’
→ 기본 텍스트 또는 짧은 음성 모의면접
→ 추가 반복 훈련이 필요하면 면접 PRO 안내
```

### 면접 PRO 직접 구매자

```text
이력서·자소서·공고 업로드 또는 기존 지원 건 불러오기
→ 자료 충분성·충돌 확인
→ 면접 준비팩 작성
→ 면접 유형 선택
→ 카메라·마이크 점검
→ 실전 모의면접
→ 녹화·전사문·리포트 확인
→ 약점 문항 재훈련
→ 다음 실전 세션에서 전후 비교
```

## 6. 기존 코드 재사용 방향

- 면접 준비팩의 답변·키워드·근거·꼬리질문 생성은 기존 `interview-pack` 도메인과 서비스를 재사용한다.
- 텍스트 모의면접의 세션·턴·리포트는 기존 `interview_sessions` 계열을 확장한다.
- 음성 입력은 새 전사 단계만 추가하고, 전사문 확인 뒤 기존 답변 평가·꼬리질문 엔진으로 합류시킨다.
- FINAL과 면접 PRO가 같은 엔진을 쓰되 권한·세션 수·보관 기능은 별도 entitlement로 구분한다.
- `user.role`이나 클라이언트 플래그로 권한을 판단하지 않는다.

## 7. 음성 개발 전 필수 선행 작업

1. `feat/final-interview-pack`을 최신 `origin/main` 기반 통합 브랜치에 보존 병합한다.
2. 현재 `/api/interview/turn`이 클라이언트가 보낸 질문을 믿는 문제를 고친다. 질문은 DB의 `pending_question`을 서버가 읽는다.
3. AI 호출 전에 턴을 원자적으로 예약하고 `client_request_id`로 중복 제출·중복 비용을 막는다.
4. 최종 리포트 생성도 중복 호출과 저장 실패 재시도에 안전하게 만든다.
5. 실제 FINAL 결과에서 텍스트 모의면접 전체 브라우저 흐름을 먼저 끝까지 검증한다.
6. 준비팩 답변·꼬리질문·근거를 모의면접 세션에 넘기는 연결을 만든다.

## 8. 권장 개발 순서

1. 브랜치 통합과 텍스트 모의면접 안전성 보완
2. 준비팩 `실전 연습에 보내기`
3. 마이크 녹음 → STT → 전사문 확인 → 기존 평가 엔진 연결
4. AI 질문 TTS
5. 카메라 셀프뷰와 브라우저 내 녹화 재생
6. 객관적인 발화 지표
7. 약점 훈련·세션 이력·전후 비교
8. 실제 사용량과 비용 확인 후 면접 PRO 가격·포함 세션 수 확정

## 9. 최종 제품 결정 제안

- 기존 PRO와 FINAL의 면접 기능은 제거하지 않는다.
- 면접 PRO는 기존 면접 기능을 모두 포함해 독립 구매가 가능하게 한다.
- FINAL과 면접 PRO의 차이는 `영상 유무`가 아니라 `한 지원 건 준비`와 `반복 훈련 과정`의 차이로 만든다.
- FINAL은 완결성과 면접 PRO 체험 입구를 담당한다.
- 면접 PRO는 영상·음성, 다양한 면접 유형, 반복 세션, 녹화 복기, 약점 재훈련, 전후 비교를 담당한다.

## 10. 판매 구성과 가격 결정

면접을 앞둔 사람에게 FINAL을 다시 사게 만들지 않는다. 서류 첨삭 상품과 면접 상품을 한 화면에
다섯 장 나열하지 말고, 진입 화면을 `서류 첨삭`과 `면접 준비`로 나눈다.

면접 준비 화면에서는 다음 두 가지만 보여 준다.

| 상품 | 기준 가격 | 대상 | 포함 범위 |
| --- | ---: | --- | --- |
| 면접 PRO 단독 | **59,000원** | 서류 제출이 끝났거나 면접만 남은 사람 | 자료 불러오기·업로드, 면접 준비팩, 영상·음성 실전 세션, 리포트, 약점 재훈련, 세션 비교 |
| FINAL + 면접 PRO | 추후 확정 | 서류 첨삭부터 면접까지 한 번에 준비하는 사람 | 현재 FINAL 전체 + 면접 PRO 전체 |

- 현재 FINAL 19,900원은 그대로 유지한다.
- 면접 PRO 단독의 초기 기준가는 59,000원으로 고정한다. 포함 세션 수와 원가가 확정되기 전 임의로 낮추지 않는다.
- FINAL 결합가와 QUICK·PRO·FINAL 구매자의 전환 가격은 실제 면접 PRO 범위·호출량을 확인한 뒤 정한다. 중복 기능과 이미 지불한 금액은 반영하되, 아직 결제 상품이나 숫자를 런타임에 하드코딩하지 않는다.
- 기존 QUICK·PRO·FINAL 구매자는 면접 PRO로 이어갈 수 있고, 이미 올린 지원자료를 다시 업로드하지 않는다.
- 면접 PRO 단독도 지원자료는 필요하지만, FINAL의 전체 서류 첨삭을 다시 실행하거나 그 비용을 받지 않는다.

무료·범용 영상면접 연습과 구별되는 핵심은 카메라가 아니다. `내 이력서·자소서·공고의 근거 → 답변팩 →
실제 발화 → 꼬리질문 → 리포트 → 약점 재훈련`이 한 지원 건 안에서 이어지는 것이 유료 가치다.

### 기존 상품에서 면접 PRO로 이어지는 파이프라인

네 경로 모두 새 지원 건을 복제하지 않고 같은 `ApplicationCase`를 사용한다. 면접 PRO 시작 시점의
문서 버전을 새 `SubmissionSnapshot`으로 고정하고, 이후 원문이 바뀌어도 이미 진행한 세션의 근거는 유지한다.

| 시작점 | 이어받는 것 | 면접 PRO에서 새로 하는 것 |
| --- | --- | --- |
| 면접 PRO 단독 | 새로 올린 이력서·자소서·공고 | 면접용 자료 점검과 근거 스냅샷을 만든다. FINAL 서류 첨삭은 실행하지 않는다. |
| QUICK → 면접 PRO | 원문, QUICK 첨삭 결과, 확인이 필요한 사실 | 면접에 필요한 추가 자료만 묻고 전체 면접 준비팩·실전 훈련으로 이어간다. |
| PRO → 면접 PRO | 원문 근거, 예상질문, 답변 핵심포인트, 면접 리스크 | 기존 질문·리스크를 초기 훈련 계획으로 전환하고 부족한 답변만 만든다. |
| FINAL → 면접 PRO | 최종 첨삭본, 면접 준비팩, 키워드, 근거, 텍스트 모의면접 이력 | 같은 답변을 다시 생성하지 않고 영상·음성 세션, 발화 분석, 반복 훈련과 전후 비교를 시작한다. |

결제 권한은 서류 분석 권한과 분리한다. 면접 PRO가 시작될 때 `sourceProduct`와 원본 분석 실행을 참조하되,
QUICK·PRO·FINAL 결과를 복사하거나 덮어쓰지 않는다. 사용자가 여러 지원 건을 가지고 있다면 결제 후
어느 `ApplicationCase`로 훈련할지 명시적으로 선택하게 한다.

현재 FINAL 계열은 `gpt-5.6-sol`, 추론 강도 `high`를 사용한다. 설정 단가는 입력 100만 토큰당 4달러,

개인정보와 원문은 읽지 않고 원격 원장의 토큰 합계만 조회한 표본은 다음과 같다.

카메라는 로컬 셀프뷰·녹화로 쓰면 OpenAI 비용이 없다. 3세션 합계 음성 45분을 녹음 후 전사하는 방식은
모델에 따라 약 183~367원이다. 반면 `gpt-live-1` 실시간 음성을 45~60분 쓰면 음성 구간만 약
3,055~4,074원이고 백엔드 모델 호출비가 추가된다.

여기서 약 5,431원은 `FINAL 전체 최대`가 아니라 장문 자료로 준비팩 정상 호출 11회의 출력 상한까지
채운 계산값이다. FINAL 분석·텍스트 모의면접까지 합친 현재 계획 전체는 실제 정상 사용 약
2,500~3,500원, 긴 자료와 모든 횟수를 꼼꼼히 쓰는 사용자는 약 7,000원 안팎으로 잡는다.
이 표본을 작성할 당시에는 내부 재시도까지 고려한 운영 예산을 건당 8,000~9,000원으로 보고,
실시간 음성을 기본값으로 쓰면 10,000~13,000원까지 올려 잡았다. 그러나 아래에서 확정한 면접 PRO
하드캡 정책으로 이 판단을 대체한다. 59,000원 기본 상품에서 실시간 음성 때문에 10,000원을 넘기는
구성은 허용하지 않으며, 분량을 제한하거나 별도 추가 이용권으로 분리한다.

현재 준비팩 원장에는 `INVALID_OUTPUT` 3건의 토큰이 비어 있다. API가 응답을 만들다 출력 한도 등으로
실패한 호출도 비용이 들 수 있으므로, 예외에 usage를 보존해 원장에 남기기 전까지 실제 비용 합계는
관측치보다 높을 수 있다. 가격 확정 전 이 누락을 먼저 고친다.

원가 관점에서도 첫 영상·음성 버전은 `녹음 → STT → 기존 텍스트 평가 엔진`으로 출시하고,
실시간 대화형 음성은 별도 실험 또는 상위 요금제로 두는 것이 적절하다.

### 면접 PRO Astra 원가 정책 — 사용자 확정

- 면접 PRO 단독 판매가는 `59,000원`을 유지한다.
- Astra는 기업·직무·지원자료 통합 분석, 중요한 근거 충돌 재검증, 최종 종합평가를 담당하는 핵심 기본 모델이다.
- 질문 사이의 반복 분류·통계·형식 변환과 비용 민감도가 큰 경로는 코드 또는 더 가벼운 모델로 처리할 수 있다. 이는 품질을 숨겨 낮추는 목적이 아니라 Astra가 필요한 판단에 예산을 집중하기 위한 라우팅이다.
- 사용자 1명당 전체 AI·STT/TTS 원가의 정상 목표는 `3,000~5,000원`, 내부 소프트 경고는 `7,000원`, Astra High 제한선은 `9,000원`, 구매 건당 절대 상한은 `10,000원`으로 둔다.
- `10,000원`은 평균 목표가 아니라 모든 제공량과 허용된 재분석을 소진한 경우에도 넘지 않아야 하는 하드캡이다.
- 공급자 usage가 없거나 계산할 수 없는 호출은 0원으로 기록하지 않고 `미확정`으로 남긴다. 호출 전에는 최대 예상 비용으로 예산을 예약하고, 완료 후 실제 usage로 정산한다.
- 카메라 셀프뷰·로컬 녹화는 AI 원가에 포함하지 않는다. 서버 영상 보관이 생기면 저장·전송 비용을 별도 계측한다.
- 반복되는 지원자료·평가기준은 안정적인 프롬프트 앞부분에 두어 캐시를 재사용한다. OpenAI 공식 문서의 현재 단가와 캐시 정책은 출시 전 다시 확인한다.

현재 로컬 시안에는 실제 AI 호출이 없으므로 `src/domain/interview-pro-cost-policy.ts`에 정책 상수와 사전 차단 판정만 먼저 고정했다. 실제 호출을 연결할 때는 세션 원장·호출 예약·실제 원화 환산과 함께 서버 경계에서 강제해야 한다.

## 12. 면접 PRO의 두 가지 실전 루트

기업이 AI를 채용에 활용하는 흐름은 별도 대비 가치가 있다. 다만 `기업 AI면접`은 하나의 동일한 시험이 아니다.
역량·성향검사, 게임, 고정 질문형 녹화면접, 대화형 꼬리질문, 온라인 사람 면접이 서로 다른 조합으로 쓰인다.
기업이 자체 모델을 직접 개발하기보다 JOBDA·에듀스 같은 외부 솔루션을 도입하고 회사·직무별 가중치와
문항을 설정하는 경우가 많으므로, 특정 회사의 비공개 점수 공식을 맞힌다고 약속하지 않는다.

면접 PRO 시작 화면은 다음 두 루트와 보조 선택지로 나눈다.

### A. 기업 AI채용전형 대비

목적은 `AI 점수 해킹`이 아니라 실제 응시 형식 적응과 검증 가능한 응답 품질 개선이다.

- 사용자가 받은 응시 안내문·문자·메일·화면을 올리거나 솔루션 유형을 선택한다.
- 준비 시간, 답변 시간, 재응시 가능 여부, 문항 수, 고정형/대화형 여부를 추출해 같은 형식으로 연습한다.
- 기본면접, 경험면접, 상황면접, 가치관·직무 질문과 1분 자기소개를 제공한다.
- 결과는 답변의 질문 적합성, 지원자료 근거, 구조, 구체성, 시간, 음성 명료도, 침묵·반복어처럼 설명 가능한 항목만 제공한다.
- 카메라 화면은 환경 점검과 자기 복기에 쓰고 표정·시선·외모 점수나 합격 예측은 제공하지 않는다.
- 기업·솔루션마다 가중치가 다르므로 `이 점수면 통과` 또는 `카메라를 이렇게 보면 가산점`이라고 단정하지 않는다.
- 성향검사·인지게임 전체 복제는 별도 제품 규모이므로 초기에는 영상·질의응답 구간에 집중한다.

### B. 일반·대면 면접 실전훈련

현재 면접 PRO의 본래 방향이다.

- 지원서·직무·공고를 기반으로 실무진/인사/임원 면접을 구성한다.
- 답변 내용에 따라 동적으로 꼬리질문을 낸다.
- 답변의 근거와 자료 충돌, 확인되지 않은 수치, 회피한 질문을 추적한다.
- 세션 리포트에서 약점 문항을 고르고 변형 질문으로 다시 연습한다.
- 첫 세션과 재연습의 답변 구조·시간·명료도·근거 충실도를 비교한다.

### C. 어떤 면접인지 모르겠어요

응시 안내문을 읽어 A/B를 추천하거나, 안내가 없으면 `고정 영상질문 + 사람 면접형 꼬리질문`을 한 번씩
짧게 체험시킨 뒤 사용자가 주 훈련 루트를 정하게 한다.

두 루트는 서로 다른 제품이 아니라 같은 면접 PRO 권한 안의 모드다. 준비팩·근거·연습 이력은 공유하고
세션 형식만 달라진다.

## 13. 에듀스 inFACE 참고와 무아의 차별점

에듀스 inFACE는 다음을 한 플랫폼에 묶는다.

- 1분 자기소개
- 텍스트 채팅 면접
- AI휴먼 면접관
- 답변을 분석해 다시 묻는 대화형 면접
- 실무·임원·인성·기업맞춤형·자소서 기반 면접
- 기본면접·성향·상황대처·AI게임·심층면접을 포함한 약 40~50분 AI역량평가
- 답변 가이드·예시·AI 코칭과 대학 제휴형 취업 콘텐츠

무아는 이 범위를 그대로 복제하지 않는다. 무아의 핵심은 `실제 제출 문서 버전과 원문 근거 → 첨삭 결과 →
면접 답변 → 실제 발화 → 꼬리질문 → 약점 재훈련`이 끊기지 않는 것이다. 기업 AI채용 루트에서도
게임·표정 점수보다 지원자료와 답변의 사실 일치, 질문 적합성, 전달 구조를 우선한다.

## 14. AI 사람 면접관 구현 결정

실시간으로 생성되는 사람형 면접관은 첫 출시의 필수 기능이 아니다. 현실감에는 도움이 되지만 질문 품질·
피드백 정확도와 직접 같은 것은 아니며, 지연·분당 비용·모바일 안정성·개인정보 처리업체 추가 부담이 크다.

### 1단계 — 출시 권장

- 실무진·인사·임원 3개 면접관 캐릭터(정적 이미지 또는 짧은 사전 제작 영상 루프)
- 질문 TTS와 `질문 중 / 답변 대기 / 기록 중` 상태 애니메이션
- 사용자의 카메라 셀프뷰, 녹화, 재생
- 브라우저 `getUserMedia`·`MediaRecorder` + STT + 기존 Responses API 평가

이 정도면 사용자는 화면 속 면접관 앞에서 답하는 느낌을 받으면서도, 질문은 무아의 근거 기반 엔진이
통제하고 영상 생성 장애가 세션을 망치지 않는다.

### 2단계 — 효과 확인 후

- 사전 제작한 말하기·듣기·고개 끄덕임 영상을 질문 오디오에 맞춰 전환
- 면접 유형별 배경·인원 구성
- A/B 테스트로 아바타가 세션 완료율·재연습률·유료 만족도를 실제로 높이는지 확인

### 3단계 — 필요할 때만 실시간 아바타 API

- HeyGen LiveAvatar: 실시간 스트리밍 아바타에 외부 LLM을 붙이기 쉬운 선택지
- Tavus CVI: React 구성요소와 영상 대화 제어가 더 깊게 필요한 경우
- D-ID Agents/Streams: 사진 기반 인물과 스트리밍 발화를 빠르게 붙이는 경우
- OpenAI Realtime API: 음성 대화의 두뇌·입출력을 담당할 수 있지만 얼굴 영상은 만들지 않으므로 위 아바타 계층과 별도다.

실시간 아바타는 공급자별 한국어 자연스러움, 첫 응답 지연, 모바일 연결 복구, 동시접속 단가, 세션 데이터
보관 정책을 실제 PoC로 비교한 뒤 선택한다. 출시 전에 공급자를 제품 구조에 고정하지 않는다.

## 15. 참고한 영상에서 가져올 것과 버릴 것

- 진로나래이션 영상: 카메라 환경·음성 안정성·직무 연결 답변을 사용자가 스스로 점검하는 온보딩에 참고한다.
- KBS 사례와 대전대학교 사례: 면접 유형 선택 → 가상 면접관 질문 → 즉시 피드백 흐름을 참고한다.
- 호랭몬 실전 모의면접: 실제 사람 면접관의 질문 뒤 사용자가 직접 멈추고 답하는 단순한 압박감과 템포를 참고한다.
- 그대로 가져오지 않을 것: 근거가 공개되지 않은 표정·시선 점수, 외운 표정 연기 유도, 기업별 비공개 알고리즘 통과 보장.

## 16. 사람인 AI 모의면접 경쟁 분석

사람인 AI 모의면접은 무아 면접 PRO의 `일반·대면 면접 실전훈련` 루트와 직접 경쟁한다.

### 사람인이 이미 제공하는 범위

- 이력서 내용 분석 기반 맞춤 질문
- 사람인 채용공고 URL 기반 기업·직무 맞춤 질문
- 직무·인성·종합, 대기업·공기업·유니콘 등 전형별 질문
- 답변에 따라 달라지는 꼬리질문
- 연습면접 5문항과 실전면접 11문항
- 질문·답변 AI 가이드, 실시간 행동 코칭, 답변별 피드백
- 종합리포트, 상세피드백, 합격가이드
- 답변 영상, 답변 첨삭, 예시답안, 예상질문
- 서로 다른 직급·연차·성격의 AI휴먼 면접관 6명
- 모바일/PC 교차 사용, 중단 지점 이어하기, 영상 3개월 보관

기사 기준 사람인은 AI휴먼을 자체 개발했고 350만여 건의 음성·영상 데이터와 300시간 이상의 TTS 학습
데이터를 활용했다고 밝힌다. 이 부분은 짧은 기간에 그대로 따라갈 대상이 아니다. 반면 이력서·공고 입력,
질문 생성, 동적 꼬리질문, 녹음·전사, 세션 저장, 답변별 피드백, 결과 리포트의 제품 골격은 현재 무아의
기존 코드와 범용 API를 이용해 구현 가능한 범위다.

### 사람인의 강한 해자

- 대규모 구직자 유입과 채용공고·기업 데이터
- 이력서가 이미 저장돼 있어 입력 마찰이 작음
- 저가 체험·이용권을 감당하는 규모와 유통력
- 자체 AI휴먼·TTS와 대규모 음성·영상 데이터
- 사람인 브랜드에서 오는 신뢰와 결제 전환

이 영역에서 무아가 `우리도 AI 사람이 질문합니다`로 정면승부하면 불리하다.

### 무아가 이겨야 하는 영역

1. **근거 연결**
   - 질문과 답변이 이력서 요약이 아니라 정확한 문서 버전·문단·사용자 확인 사실에 연결된다.
   - 자료에 없는 성과·수치·직책을 만들지 않고 충돌을 먼저 확인한다.

2. **첨삭에서 면접까지의 연속성**
   - QUICK·PRO·FINAL에서 찾은 문제와 최종 첨삭본이 면접 질문·답변·훈련 계획으로 그대로 이어진다.
   - FINAL 사용자는 같은 답변을 다시 생성하거나 자료를 다시 올리지 않는다.

3. **한 지원 건을 끝내는 훈련 과정**
   - 1회 응시권보다 `답변 준비 → 암기 → 실전 → 복기 → 약점 재훈련 → 전후 비교`를 하나의 프로그램으로 판다.
   - 리포트가 끝이 아니라 다음 세션의 질문과 훈련 과제를 자동으로 바꾼다.

4. **설명 가능한 피드백**
   - 막연한 합격 진단 대신 어느 질문의 어느 발화와 어느 원문 근거 때문에 보완이 필요한지 보여 준다.
   - 사용자가 답변 수정안을 수락·거절·복원할 수 있고 변경 이력을 보존한다.

5. **프라이버시 선택권**
   - 영상 서버 저장 없이 로컬 복기만 하는 선택지를 제공한다.
   - 저장 시 보관기간과 삭제 시점을 명확히 하고 서비스 개선용 재사용은 별도 동의를 받는다.

### 59,000원 가격이 성립하는 조건

사람인은 기사 기준 1회 정가 27,500원, 출시 할인 10,000원, 3회권 25,000원을 제시했다. 따라서 무아가
단순 모의면접 몇 회를 59,000원에 팔면 가격 경쟁력이 없다. 59,000원은 다음을 모두 제공하는
`한 지원 건 면접 완성 프로그램`이어야 한다.

- 면접 준비팩 전체와 근거·사실 충돌 확인
- 기업 AI채용전형 대비/일반면접 두 모드
- 여러 실전 세션과 약점 집중 재훈련
- 세션 전후 비교와 개인 훈련 계획
- 문서→답변→발화의 근거 추적
- 영상 로컬 복기 또는 명시적 저장 선택
- 필요하면 최종 답변을 다시 다듬는 제한된 AI 코칭

포지셔닝은 `사람인보다 더 현실적인 AI휴먼`이 아니라 `내 지원서 한 건을 실제 면접에서 말할 수 있을
때까지 끝내 주는 증거 기반 면접 훈련`으로 둔다.

### 개발 난이도 판단

- 빠르게 가능한 것: 자료·공고 기반 질문, 동적 꼬리질문, 면접 유형, 타이머, 녹음·전사, 세션 복원,
  답변 피드백, 리포트, 약점 재훈련. 상당 부분은 현재 준비팩·텍스트 모의면접 코드를 재사용한다.
- 시간이 필요한 것: 모바일 카메라·마이크 안정성, 대용량 영상 업로드/재개, 브라우저별 녹화 포맷,
  중복 호출·결제 복구, 보관·삭제·동의, 실제 사용자 eval.
- 그대로 따라가기 어려운 것: 자체 실시간 AI휴먼, 6개 고품질 인물, 저지연 한국어 TTS, 행동평가 모델,
  수백만 건 학습 데이터. 초기 경쟁 범위에서 제외한다.
