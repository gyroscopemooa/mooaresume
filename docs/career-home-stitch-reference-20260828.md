# [워크트리 초안 · feature/codex-plan] Stitch 커리어 홈 참고 적용

상태: **`/career` 홈 전용 — main 미통합**.

## 참고 자료

사용자가 제공한 `stitch_career_mind_lab (2).zip` 및 동형 ZIP의 Career Command Center 화면을 참고했다. 원본 이미지·브랜드명·문구·코드를 복제하지 않는다.

## 가져오는 원리

- 다크 차콜 바탕, 낮은 채도의 에메랄드 포인트, 얇은 테두리
- 좌측 내비게이션 + 밀도 있는 데이터 모듈
- 모노 메타 정보, 작고 정돈된 라벨, 결과가 아닌 다음 행동 우선

## 안전한 적용

- 49.5%, 추천 직업, 사용자별 점수처럼 실제 근거 없는 수치를 홈에 표시하지 않는다.
- 세 검사 문항 수·소요 시간과 기존 링크만 실제 정보로 사용한다.
- 검사 결과·마이페이지·대시보드 경로는 바꾸지 않는다.
