# MOOA 자소서 분석 일관성과 둥글게 다듬기 철학

## 목적

MOOA Resume는 자기소개서에 하나의 절대적인 정답이 있다고 주장하지 않는다. 자기소개서를 읽는 사람마다 경험, 직무 관점, 조직 문화, 문체 선호가 다르기 때문이다.

MOOA의 목표는 특정 인사담당자 한 명의 취향에 맞춘 정답 문장을 만드는 것이 아니다. 지원자의 사실과 개성을 유지하면서, 여러 유형의 평가자가 읽어도 불필요하게 감점할 가능성이 높은 모서리를 줄이는 것이다.

핵심 문장은 다음과 같다.

> 정답을 만들기보다, 떨어질 이유를 줄인다.

## 1. 같은 입력에서 결과가 달라지는 문제

생성형 AI는 같은 입력과 같은 조건에서도 표현 선택, 문장 순서, 예시의 배치가 조금씩 달라질 수 있다. 최종 문장이 100% 동일하지 않은 것 자체는 오류가 아니다.

다만 결과의 변동 범위는 상품과 작성 상태에 따라 통제해야 한다.

| 유형 | 허용되는 변동 | 운영 원칙 |
| --- | --- | --- |
| QUICK | 작음 | 원문 보존을 우선하고 같은 문제에는 비슷한 수정 방향을 유지한다. |
| PRO POLISH | 작음 | 완성된 글을 크게 흔들지 않고 안정적인 검수와 표현 개선을 제공한다. |
| PRO BUILD | 중간 | 부족한 근거를 보완하고 더 적합한 구조나 경험을 찾을 수 있다. |
| PRO CREATE | 가장 큼 | 처음부터 작성하므로 소재 배치와 구성 선택에 여러 좋은 답이 있을 수 있다. |

### 반드시 일관되어야 하는 것

- 사실관계
- 경력, 기간, 숫자, 자격증 등 객관 정보
- 문항의 의도에 대한 해석
- 공고의 핵심 요구사항
- 핵심 진단과 주요 문제
- 사용하기로 선택한 경험과 근거
- 수정 방향과 사실성 기준

### 달라도 되는 것

- 문장 표현
- 문장 순서의 세부 조정
- 같은 의미를 전달하는 어휘 선택
- 문단 연결 방식
- CREATE에서의 대안적인 소재 배치

따라서 MOOA가 추구해야 하는 것은 매번 똑같은 문장이 아니라, **같은 판단 기준·일관된 사실·일관된 수정 방향**이다. 최종 문장이 소폭 달라지는 것은 허용하지만, 진단과 경험 선택이 실행마다 크게 출렁이는 것은 허용하지 않는다.

## 2. 분석과 최종 작성의 분리

분석과 작성은 개념적으로 분리한다.

먼저 다음 판단을 고정한다.

- 원문 구조와 문항 의도
- 공고 요구사항
- 핵심 문제
- 활용할 경험
- 부족하거나 확인이 필요한 근거
- 수정 방향

그다음 고정된 분석 결과를 바탕으로 최종 문장을 생성한다. 이렇게 하면 표현은 조금 달라져도 왜 고쳤는지, 어떤 경험을 사용하는지, 어떤 문제를 해결하는지는 일관되게 유지할 수 있다.

최초 결과는 버전으로 저장한다. 새로고침이나 재진입 때문에 자동으로 다시 생성하지 않으며, 사용자가 명시적으로 다시 다듬기 또는 다른 구성 보기를 선택한 경우에만 새 버전을 만든다.

- 원본
- 첨삭본 V1
- 사용자 수정
- 첨삭본 V2

이런 식으로 결과의 계보를 보존한다.

PRO CREATE에서는 여러 좋은 구성안이 존재할 수 있다. 사용자가 구성 A를 선택하면 이후 작성은 선택한 구성과 스타일을 기준으로 고정한다. 작성 스타일도 같은 지원서 안에서 유지되도록 Application Case의 설정으로 취급한다.

## 3. 자소서를 둥글게 다듬는다는 의미

“둥글게 만든다”는 개성과 강점을 지우고 무난한 문장으로 바꾼다는 뜻이 아니다. 사실과 개인 경험이라는 중심은 남겨두고, 읽는 사람에 따라 불필요한 오해나 감점으로 이어질 수 있는 모서리를 깎는다는 뜻이다.

### 대부분의 평가자에게 공통으로 위험한 모서리

- 질문에 제대로 답하지 않음
- 지나치게 추상적인 자기평가
- 근거 없는 강점 주장
- 앞뒤 논리의 불일치
- 공고와의 관련성이 약함
- 같은 경험을 반복 사용함
- 읽기 어려울 정도로 문장이 김
- 이력서와 자기소개서의 기간·숫자가 충돌함
- 본인이 한 일인지 팀이 한 일인지 불분명함
- 실제 사실보다 강한 의미를 단정함
- 불필요하게 공격적이거나 과장된 표현

이런 문제는 문체 취향과 관계없이 먼저 줄여야 하는 품질 리스크다.

### 정답으로 단정할 수 없는 영역

- 첫 문장을 강하게 시작할지 담백하게 시작할지
- 스토리를 먼저 보여줄지 결론을 먼저 보여줄지
- 어느 정도의 자신감 있는 표현이 적절한지
- 문단의 감정 강도와 리듬

이 영역은 평가자와 상황에 따라 달라질 수 있으므로, AI가 하나의 방식을 절대적인 정답처럼 강요하지 않는다.

### 유지해야 하는 것과 제거해야 하는 것

| 유지 | 제거 또는 완화 |
| --- | --- |
| 개인의 실제 경험 | 과장 |
| 구체적인 행동 | 논리적 비약 |
| 본인만의 맥락 | 질문 이탈 |
| 확인 가능한 성과 | 근거 없는 주장 |
| 직무와 연결되는 강점 | 장황함 |
| 자연스러운 개성 | 불필요한 공격성 |

둥글게 다듬은 결과는 밋밋한 원이 아니라, 개성과 강점은 살아 있고 잡힐 만한 모서리는 줄어든 글이어야 한다.

## 4. 작성 스타일과의 관계

담백하게, 균형 있게, 강점 살리기는 서로 다른 품질 기준이 아니다. 세 스타일 모두 공통적인 사실성·근거성·질문 적합성 기준 안에서 표현의 적극성만 조절한다.

- **담백하게**: 제공된 사실에 가장 가까운 표현을 사용한다.
- **균형 있게**: 사실을 지키면서 경험의 의미와 직무 연결을 자연스럽게 찾는다.
- **강점 살리기**: 같은 사실 안에서 강점과 의미를 적극적으로 발굴하되, 확인이 필요한 내용은 질문하고 허위 성과는 만들지 않는다.

스타일이 달라져도 위험한 모서리를 줄이는 공통 원칙은 유지한다. 강점 살리기가 과장이나 허위 작성을 허용하는 모드가 되어서는 안 된다.

## 5. 제품·AI 구현에 반영할 원칙

이 문서는 문장 표현을 획일화하는 규칙이 아니라 제품 철학과 품질 기준이다. 구현에서는 다음 제약을 우선한다.

1. 없는 사실, 역할, 성과, 숫자, 자격을 만들지 않는다.
2. 사실과 해석을 구분하고, 확인이 필요한 내용은 표시하거나 질문한다.
3. 분석 결과와 최종 작성 결과를 분리한다.
4. 결과를 버전별로 저장하고 새로고침만으로 재생성하지 않는다.
5. QUICK과 POLISH는 안정성을, BUILD는 보완을, CREATE는 선택 가능한 구성의 다양성을 우선한다.
6. 결과가 달라질 때에도 핵심 사실과 판단 근거는 유지한다.
7. “둥글게”를 개성 제거 또는 무난함 강제로 해석하지 않는다.

MOOA는 합격 확률이나 특정 담당자의 반응을 단정하지 않는다. 대신 지원자의 실제 경험을 더 정확하고 설득력 있게 전달하고, 여러 평가자에게 불필요한 감점으로 읽힐 가능성을 줄이는 방향을 제공한다.

## 2026-09-22 보완 — 내용과 함께 전달 방식도 읽힌다

운영자의 직무·커리어 컨설팅 경험에 따른 제품 철학이다. 자소서에 대한 회의감을 세대 문제로 보거나 지원자를 훈계하지 않는다. 읽는 사람에 따라 직무 경험뿐 아니라 글쓰기, 논리, 문장 호응, 어조와 설명 방식에 주목할 수 있다. 모든 회사의 평가 기준이 같다는 주장이 아니다.

핵심을 정리하고 근거를 연결해 상대에게 전달하는 과정은 의사소통과 서류작성 능력을 살펴보는 단서가 될 수 있다. 문서의 전달력 평가와 지원자의 실제 업무 능력·인성·가치관에 대한 단정은 구분한다. 원문 근거와 독자의 이해에 미치는 영향을 설명하고, 명확한 오류·정성 판단·선택적인 문체 취향을 구분한다. 사소한 표현을 탈락 사유로 과장하지 않고 잘 전달되는 내용과 고유한 말투는 살린다.

편의점 아르바이트도 소재 이름만으로 낮게 평가하지 않는다. 실제로 제공된 행동·판단에서 직무와 연결할 근거를 찾는다. 근무 사실만으로 재고 관리나 고객 응대 등을 했다고 추정하거나 없는 성과·회사 정보를 만들어 연결하지 않는다. 부족한 사실은 확인 질문으로 남긴다. 설명을 다듬는 일과 사실을 꾸미는 일은 다르다.

홈은 “자소서, 결국 소설 아닌가요?”라는 질문에서 시작해 내용과 전달 방식의 중요성, 평가 관점의 다양성, 실제 경험의 가치를 알린다. 상세 프롬프트·평가 가중치·컨설팅 절차는 공개하지 않는다. QUICK/PRO/FINAL 공통 프롬프트 quick-3.5에 적용하며 기존 점수 체계·스키마는 유지한다.

### 같은 날 사용자 보완 — 전달력은 여러 관점 중 하나

이 철학의 결론을 “전달 능력을 보여주는 문서” 하나로 축소하지 않는다. 경험과 직무 연관성, 논리, 문장 호응, 생각과 소신, 태도와 표현, 커뮤니케이션·문서작성·의사전달 등 다양한 관점에서 읽힐 수 있다는 것이 중심이다. 내용만 보거나 거짓말·소설이라는 관점으로만 접근하면 함께 드러나는 강점과 세밀한 요소를 놓칠 수 있다. 무아레쥬메는 이 관점들을 함께 고려한다. 글만으로 실제 인성·능력을 확정하는 것은 여전히 금지한다.

홈 제목은 “자소서, 거짓말 아닌가요?”, 답의 첫 문장은 “당연히 거짓말로 작성하면 안 됩니다.”로 변경했다. 소설·구라 표현은 방문자의 질문을 나타내는 작은 말풍선에서만 사용한다. 본문은 여러 평가 관점을 설명하고 상세 컨설팅 방법은 노출하지 않는다.
