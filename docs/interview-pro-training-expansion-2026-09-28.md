# 면접 PRO — 첨부 요구안 통합 구현

기준일: 2026-09-28. 로컬 `/dev/interview-pro-v2` 전용. 운영 공개·DB 변경·배포·유료 API 실호출 없음.

## 정리 원칙

사용자 첨부 `154c9cb1-7d66-4ca0-b478-995f5e95ccd7/pasted-text.txt`의 12개 묶음을 기존 녹화/STT/Astra/계측 모듈과 대조했다. 기존 엔진을 복제하지 않고 설정, 질문 유형별 평가, 답변 원문 표시, 후속 연습과 이력을 연결했다. 첨부의 예시 수치나 점수는 실제 데이터로 사용하지 않았다.

AI 내용 피드백이 주 화면이다. 파형·피치·영상 기준점은 기본 접힌 참고 근거다. 과학적으로 검증하지 않은 발음 점수·정확한 응시율·감정/인성/합격 판단은 만들지 않는다. 모든 유형을 STAR 하나로 평가하지 않고 질문별 기준을 적용한다.

## 사용 흐름

1. 전형 선택 → **내 면접 설정 · 자료 기반 질문 만들기**. 일반 회원 로그인을 함께 해야 본인 저장 자료를 읽을 수 있다. 관리자 권한만으로 타인 자료를 읽을 수 없다.
2. 기존 질문에 시간/평가 설정만 적용하거나, 외부 전송 동의 후 **맞춤 질문 생성·적용**. 현재 기록이 있으면 초기화 확인을 거친다. 취소 시 기존 연습을 유지한다.
3. 장비 확인에서 입력 방식 선택. 타자는 권한 요청 없이 연습 가능. 영상 프레이밍 점검은 선택 기능이다.
4. 질문 답변 → **답변 피드백·꼬리질문 보기** → 결과에서 **답변 1/2/3…** 선택. 음성은 받아쓰기 후 수정·확인, 타자는 저장한 답변을 불러온다.
5. 관리자 연결 및 전송 동의·내용 확인 후 **AI 답변 분석**. 핵심 개선점→유형별 기준→원문 표시→키워드→후속 연습. 기술 근거는 필요한 경우만 펼친다.
6. 같은 질문 또는 꼬리질문 재연습 → 다시 분석. 결과의 훈련 기록에서 이전 답변과 비교한다. 새로고침/탭 종료/설정 초기화 시 기록은 사라진다.

## 구현 구조 및 보안

- 도메인: `interview-training.ts`가 설정/질문 계약, 텍스트 관찰, 카메라 샘플 집계, 시도 비교를 담당.
- AI 계약: `interview-feedback.ts`의 기존 v1 결과는 읽기 호환 보존. 실행은 v2 기준·키워드·원문 표시·후속 질문을 요구. 서버가 원문 인용/유형별 기준 수·이름/새 수치 등을 검증한다. 이것이 의미적 환각 전체를 차단한다는 뜻은 아니다.
- 내용 분석은 `feedback-gateway.ts`, 질문 생성은 `/api/dev/interview-pro/questions`. Responses Structured Outputs, 모델 환경설정, `store:false`, 최대 출력 제한, 자동 재호출 없음.
- 자료 가져오기는 `/api/dev/interview-pro/materials`. 사용자 세션 RLS 클라이언트만 사용하고 지원 건·문서·버전마다 소유자를 제한한다. service-role 키 사용 안 함. 읽은 자료를 자동으로 AI에 전송하지 않는다.
- 기존 개발환경/루프백/admin/동일 Origin/본문 크기/동시1·시간당12/UUID+요청내용 중복 과금 방지 경계를 재사용. 운영용 사용자별 원가 원장·분산 턴 예약은 별도 필요하다.
- UI는 `training-setup`, `training-insights`, `camera-setup-guide`로 분리. 기존 녹화/분석 스튜디오에 연결. 전역 폰트/zoom/다른 제품 CSS는 변경하지 않았다.
- 기술 참고: [OpenAI Structured Outputs 공식 문서](https://developers.openai.com/api/docs/guides/structured-outputs). 스키마 준수와 사실 검증은 별개이므로 서버 인용 검증을 추가했다.
