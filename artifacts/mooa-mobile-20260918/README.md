영어 AI 분석, 글로벌 결제, AI 이력서 앱 결제, 신규 가입·계정 삭제, 앱용 약관/개인정보 고지, 스토어 등록은 남은 작업입니다. 실제 기기에서 결제와 PDF 공유를 검증했다는 의미가 아닙니다.

상세 개발/연결 방법과 정확한 지원 범위는 `apps/mobile/README.md`를 참고하세요.
